WORKSHEET 02—01 · STUDENT NEEDS

大学生のニーズ一般論ではなく、南茨木・国際学生寮という今回の条件から導く。

対象は「国際交流に興味がある学生全般」ではない。まず、進学・留学・長時間通学などにより住居を必要とする学生。その入居判断を支える必須条件の上に、「お互いが、留学先」という体験価値を選べる形で重ねる。

結論

住居として成立することが先。
国際交流は、入居理由と決めつけず、選べる付加価値として検証する。

前提：これは、配布課題が設定された時点へ戻って検討する歴史的な仮想再提案です。2026年現在、対象地にはコスモグラシア南茨木が完成しており、同物件は事後ベンチマークとして扱います。

00 / SUMMARY

ニーズを
三層に分ける

「欲しい設備」を並べる前に、入居を決める条件、暮らしを続ける条件、コンセプト固有の価値を分離する。三層の証拠の強さは同じではない。

LAYER 1 · MUST 選択条件

住居として外せない

総費用、大学までの実移動、周辺利便、静かで安全に一人になれる居場所。ここで競合水準を外すと、交流価値があっても選ばれない。

LAYER 2 · SUPPORT 継続条件

生活を立ち上げやすい

家具・ネット、多言語契約、保証、行政手続、緊急時対応。特に留学生や初めて一人暮らしをする学生の摩擦を減らす。

LAYER 3 · VALUE 要検証

交流を自分で選べる

一人になれる場所へ退避できる前提で、食・言語・生活文化を日常的に交換できる。ただし、この価値への追加家賃を払う意思は未確認。

優先順位：「交流できる寮」ではなく、「安心して住める寮に、交流という選択肢がある」と定義する。
01 / TARGET

誰のニーズを
考えるか

住宅需要と国際交流への関心を混同しない。最初に狙うのは、体験のためだけに引っ越す人ではなく、すでに下宿・転居の必要がある人である。

PRIMARY TARGET

もともと南茨木周辺で
住居を探す必要がある学生

遠方から進学する新入生、日本で住居を探す留学生、長時間通学から転居を考える学生。OICだけでなく、阪急・モノレール沿線の大学へ通う学生を含む。

共通の用事：限られた予算で、通学と日常生活を無理なく回し、安心して休める拠点を確保する。

候補セグメント

大学寮の期間・対象から外れる層

OIC I-Houseは入寮が原則1年。2年目以降、他大学生、大学寮へ入れなかった学生は候補になり得る。ただし人数・応募倍率・待機数は未確認。

主対象にしない

交流体験だけで実家を出る学生

国際交流への関心が、そのまま長期入居や家賃プレミアムにつながる証拠はない。通い型・短期型で別に検証する。

02 / CONDITIONS

今回だけの
五つの条件

ニーズの根拠になる立地・市場・競合・コンセプト条件。全国の大学生一般へ広げず、この計画へ効く範囲だけを使う。

01

二路線の結節点

阪急3分
モノレール5分

単一大学の門前ではなく、OIC、阪大方面、大阪・京都方面へ動けることが強み。

現行物件の公開値。玄関から教室までの時間、待ち時間、定期代は別途確認。
02

同じ場所に強い基準商品

139室
食事・家具・管理

コスモグラシア南茨木には基本設備が揃う。設備を足すだけでは、新しいニーズへの回答にならない。

主要3費目は月 10万6,200〜11万7,700円。一方、OIC周辺の大学契約物件平均は家賃＋共益費 66,976円（2024年度値、費目が異なる）。
03

高等教育機関の私費留学生

費用78.9%
通学67.3%

交流より先に、家賃・初期費用、学校までの距離、周辺の暮らしやすさが選ばれている。

周辺利便 43.3%。日本人との交流 2.5%、留学生同士の交流 3.1%。全国の高等教育機関在籍の私費外国人留学生の値で、OIC限定ではない。なお、配布資料の「学生の声」は保護者回答であり、学生本人の直接ニーズには数えない。
04

徒歩圏に既存の国際寮

個室＋6人1ユニット
月64,200円・原則1年

OIC I-Houseは168室、RMによる生活・日本語支援もある。G-Houseも国内学生と留学生の混住。「混住」「共有リビング」「地域交流」だけでは差別化にならない。

05

便利だが、居住摩擦がある敷地

交通環境 × 住宅・病院

幹線道路、鉄道・モノレール、隣接住宅・マンション、病院が近い。移動利便と同時に、睡眠、学習、視線、夜間動線を守る必要がある。

03 / REASONING

条件からニーズを
どう割り出したか

事実から直接「欲しい空間」へ飛ばず、学生の生活上の意味を挟む。最後の列がワークシートへ残すニーズである。

今回の事実学生にとっての意味導かれるニーズニーズの確度
二路線＋OIC徒歩・自転車圏 大学、アルバイト、課外活動を一つの交通手段に固定せず回せる。 玄関から教室までの時間・交通費・雨天時を含め、移動を選べること。 根拠のある推論
高等教育機関の私費留学生は費用78.9%、通学67.3%を重視 交流以前に、毎月払えることと授業へ無理なく通えることが選択条件。 家賃だけでなく年間総支払額が分かり、必要なサービスを選べること。 根拠のある推論
同一地の食事付き学生住宅は月10万円超 管理・食事を含む住宅市場はあるが、価格差の理由が見えないと比較できない。 食事・管理・光熱・ネット・初期費用を同条件で比較できること。 根拠のある推論
交通施設と住宅・病院が近接 利便性の裏側で、睡眠・集中・帰宅時の安心が損なわれる可能性がある。 騒音・光・視線から退避し、静かに休み学び、一人になれる居場所。 根拠のある推論
保証人を求められた留学生48.7% 部屋があっても、契約・保証・日本の生活ルールで入居が止まり得る。 保証、多言語契約、行政手続、保険、退去まで一つの窓口で進められること。 根拠のある推論
既存国際寮は個室＋小ユニット＋RM 共有だけでなく、一人で戻れる場所と支援する人を組み合わせている。 プライバシーを保ち、必要なときだけ関係や支援へ接続できること。 根拠のある推論
高等教育機関の私費留学生では交流2.5%・3.1% 国際交流を前面に出しても、入居の主理由になるとは限らない。 交流への参加頻度を自分で選び、参加しない日も暮らしが成立すること。 未検証仮説
04 / NEEDS

優先順位つき
大学生のニーズ

上ほど入居判断への影響が強い。下ほど今回のコンセプト固有だが、同時に検証不足も大きい。

選択条件 01

総生活費を予算内で制御したい

表面家賃ではなく、共益費、光熱、ネット、食費、家具、初期費用、通学定期を含む実質月額を見通したい。

選択条件 02

大学と日常の行動先へ無理なく移動したい

阪急、モノレール、徒歩、自転車を使い分け、雨天・荷物・遅い帰宅でも生活を崩したくない。

選択条件 03

静かに休み学び、一人になれる居場所を確保したい

交通環境の近くでも睡眠、学習、オンライン通話を守り、共同生活から退避したい。既存事例では個室が多いが、今回の部屋形式への選好は要検証。

継続条件 04

一人暮らしをすぐ始め、困った時だけ頼りたい

家具・ネットを整え、契約、保証、行政手続、病気・災害時の相談を迷わず進めたい。支援は過干渉でないことも必要。

継続条件候補 05

授業・アルバイト・生活習慣を崩さず暮らしたい

食事、共有、一人の時間を固定されず、宗教や生活習慣にも合わせたい。自炊・食事提供の選択制は解決策候補であり、需要は未確認。

体験価値 06

負担なく異文化を日常へ取り入れたい

留学生は日本の生活知識を、日本人学生は言語・異文化対応を学べる。ただし全員参加や交流価値への追加家賃を前提にしない。

05 / SEGMENTS

同じ建物でも
用事は違う

「留学生」と「日本人学生」を国籍で一括りにせず、生活上の用事で見る。入居後の相互価値は、両者の必須条件を損なわない範囲で成立させる。

留学生

日本で生活を立ち上げる

「契約や生活ルールでつまずかず、大学へ通える安全な部屋を確保したい」

  • 年間総費用と契約条件の理解
  • 保証・行政手続・医療・緊急時支援
  • 個室、宗教・食・生活習慣への配慮
  • 必要に応じた日本語・生活知識の支援
日本人学生

生活と留学準備を両立する

「普通の学生生活を崩さず、日常の中で異文化対応を試したい」

  • 競合と比較できる費用・通学条件
  • 学習・アルバイトを優先できる自由
  • 個室へ戻れること
  • 言語・文化交流の頻度を選べること
両者に共通

関係を強制されたくない

「交流する日もしない日も、自分で決めたい」

  • 一人1寝室を基本にする
  • 共有は小単位から段階化する
  • イベント参加を契約上の義務にしない
  • 生活習慣の衝突時に相談・変更できる
06 / WORKSHEET

②−①へ
記入する文章

根拠の強い必須条件を先に置き、コンセプト固有の価値には「選べる」という留保を残した推奨文案。

① 大学生のニーズ

南茨木周辺で住居を必要とする学生が、阪急・モノレール・自転車を使い分け、大学や日常の行動先へ無理なく通えること。家賃・食費・光熱費・初期費用などを含む総生活費を見通し、交通環境の近くでも静かで安全な自分の居場所で休み、学び、一人になれること。留学生を含む一人暮らしの契約・生活立上げを支えながら、食事や交流を自分に無理のない頻度で取り入れ、プライバシーを保ったまま異文化を日常へ取り入れられること。

入居の土台総費用・移動・静穏・安全
生活の支え契約・保証・生活立上げ
今回の価値選べる日常的な異文化交流
07 / BOUNDARIES

言えることと
まだ言えないこと

根拠のない断定を避けることが、チーム内でニーズを共有するための前提。数字は結論ではなく、判断範囲を示す。

確認済み

現時点で言える

  • 高等教育機関在籍の私費留学生調査では、費用・通学・利便が上位
  • 南茨木に月10万円超の学生住宅商品がある
  • OIC徒歩圏に混住型国際寮がすでにある
  • I-Houseは原則1年で、個室＋小ユニット
未検証仮説

調査しないと言えない

  • 「お互いが、留学先」への長期入居需要は未確認
  • 交流価値へ追加家賃を払う意思
  • 南茨木で必要な室数と入居者比率
  • 相部屋の受容率と家賃低減効果
書かない

根拠を越える表現

  • 「大学生は国際交流を求めている」
  • 「留学生は相部屋を好む」
  • 「競合満室だから国際交流寮も満室になる」
  • 「交流スペースを作れば交流が起きる」
08 / VALIDATION

次に、何を
確かめるか

「興味がありますか」だけでは、室数も家賃も決められない。同じ条件で価格と行動を比較し、回答上の関心と支払い行動を分ける。

PRICE TEST

価格を出した二択で測る

A｜通常の個室型学生寮
家賃・管理・食事・通学費を明示

B｜交流機能を加えた個室型学生寮
同じ費目＋プログラム頻度＋追加額を明示

「どちらに住みたいか」に加え、実際に申込・仮予約するかまで測る。

確認順

四つの不足データ

  1. 大学寮の需給：応募倍率、待機、退寮理由、2年目以降の転居先
  2. 価格付き需要：総月額別の入居意向、食事の要否、追加家賃の上限
  3. 生活の選好：個室・任意2人室、共有人数、交流頻度、部屋変更条件
  4. 敷地の実測：昼夜の騒音、夜間動線、自転車経路、玄関から教室までの時間
対象を分ける

最低でも三群で聞く

  • OICへ進学・在学する留学生
  • 海外留学を予定・志向する日本人下宿生
  • 阪急・モノレール沿線の他大学生

自宅生向けの通い型イベント調査は、長期入居調査と分ける。

判断ゲート

結果で計画を変える

  • 追加支払意思が弱い → 交流は任意・低コスト化
  • 個室希望が強い → 相部屋を標準にしない
  • 大学寮の空きが多い → 対象大学・役割を再設定
  • 騒音が大きい → 住戸配置と外皮性能を先に見直す
