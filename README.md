## 現在の停止線

- 168室は収支上限であり、法規・実配置の成立案ではない。
- 最初の設計比較は84室・91室・99戸。行政回答前に室数を確定しない。
- 84室の建物形状は5・6・7階を同じ条件で比較する。7階は整数配置のため最初に描くが、優位案ではない。
- 7%、建設費、運営費、テナント利益は、外部回答と同条件見積の前に確定しない。
- 外部送信、個人情報取得、公開イベント実施は、このリポジトリの内部準備とは別の承認対象。

詳細な更新履歴と正本一覧は [最新ワークショップ方針](docs/current-direction-2026-09-03.md) を参照してください。

## ローカル検証

追加依存は不要です。Python側は標準の `unittest` を使い、`pytest` は前提にしません。

```bash
python3 -m unittest discover -s tests -v
node --test tests/demand-model.test.mjs
git diff --check
```
