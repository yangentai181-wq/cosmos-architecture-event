# 住居ユニット収支最適化 設計仕様

**作成日:** 2026-09-03
**対象:** 2階以上の住居階と、既存「収支計算（簡易）」に準拠した採算比較
**状態:** ユーザー合意済みの条件を実装可能な形へ固定

## 1. 目的

総延床3,600㎡を固定し、次の変数を有限範囲で総当たりして、既存収支計算表の利回りを最大化する候補と、空間品質とのトレードオフを示す。

- 1ペア室の面積
- 1ユニットのペア数
- ユニット内リビングの面積
- 2階以上の1フロア面積
- 総階数

さらに、壁厚、柱型、設備シャフト、納まり調整を平面図なしで過小評価しないため、ユニット算定面積へ計画余白を加えた配置条件を使う。既定値は10%とし、5%、7.5%、10%で感度分析する。

「最適」は一案へ早合点せず、収支最大案、空間品質を加味した推奨案、代表的な比較案、パレート解を出す。パレート解とは、ある指標を良くすると別の指標が悪くなり、単純には優劣を付けられない候補群である。

## 2. ユーザー合意済みの固定条件

### 2.1 居住単位

- 最小単位は、日本人学生1名と留学生1名の同性ペア。
- 1ペアは同室の2人部屋であり、空間上は分割しない。
- 片方が退去しても、残る1名は同じ部屋へ住み続けられる。
- 収支表上の「1戸」は1ペア室で、月額賃料10万円は2人分を合わせた1室の賃料として扱う。
- ペア室面積は水回りを含まず、二段ベッド、専用机・椅子2組、2人分の収納を置く。
- ペア室はすべて外周に接し、各室に窓を設ける。

### 2.2 ユニット

- 1ユニットは複数のペア室で構成し、男女別とする。
- トイレ、独立シャワー、洗面、洗濯、ミニキッチン、リビングはユニット内で完結する。
- 各トイレ・シャワーは同時利用できる独立区画とし、浴室・便所・洗面を一体化した3点ユニットにはしない。
- 食事は1階の食堂で取る。2階以上に食堂・ダイニングテーブルは設けない。
- ミニキッチンは飲み物と夜食用として残す。
- リビングは会話と休息の場であり、食事面積を兼ねない。

### 2.3 建物・収支

- 総延床面積は3,600㎡で固定する。
- 1階に住居室を置かない。
- 2階以上は同じ床面積、同じユニット構成を反復する。
- 総階数は5〜15階を探索する。「6階未満」の過去条件は今回の探索には使わない。
- 各階の廊下等は床面積の15%とする。
- 上階の配置判定では、ユニット算定面積の10%を計画余白として追加する。これは平面図作成前の仮定であり、収支表の面積区分や単価を変更しない。
- 1階床面積と2階以上の床面積はともに建蔽率由来の800㎡以下とし、上階床面積は1階床面積以下とする。
- RC造、専有部Rank C、目的共用部Rank A、廊下等Rank C、外構Rank Cを固定する。
- 既存収支表にない土地費、借入、税、設計監理費、稼働率、NPV、階数割増は正式な比較式へ追加しない。
- 付帯事業の売上・コストは0円、運営費は月300万円とする。

## 4. 探索変数

| 変数 | 範囲 | 刻み・条件 |
| --- | --- | --- |
| 総階数 | 5〜15階 | 1階刻み |
| 2階以上の床面積 | 各階200〜800㎡のうち成立する範囲 | 1㎡刻み。1階残余が正かつ800㎡以下、上階以下にならないこと |
| ペア室面積 | 10.5〜15.0㎡ | 0.5㎡刻み |
| 1ユニットのペア数 | 2〜8ペア | 1ペア刻み |
| 1フロアのユニット数 | 1以上 | 面積と外周条件から定まる整数上限まで |
| リビング面積 | 8〜32㎡ | 1㎡刻み、かつ居住者1人あたり0.75〜2.0㎡ |
| 計画余白率 | 5%、7.5%、10% | 10%を既定値、他2値は感度分析。0〜100%の範囲外は入力エラー |

リビング範囲は食堂を兼ねない会話・休息用の探索仮定であり、法令上の最低値ではない。結果には絶対面積と1人あたり面積の両方を表示する。

## 5. ユニット面積モデル

居住者数を `2 × ペア数` とする。

- トイレ数 = `ceil(居住者数 / 4)`
- 独立シャワー数 = `ceil(居住者数 / 4)`
- 日常用洗面数 = `ceil(居住者数 / 4)`
- 洗濯設備数 = `ceil(居住者数 / 5)`
- ミニキッチン面積 = `4.0 + 0.5 × (ペア数 - 2)` ㎡
- トイレ面積枠 = 1区画1.8㎡
- シャワー面積枠 = 1区画2.4㎡
- 洗面面積枠 = 1か所1.2㎡
- 洗濯面積枠 = 1組1.5㎡
- ユニット内動線・清掃収納 = 上記諸室とペア室の小計の12%

したがって、1ユニット算定面積は次式とする。

```text
ペア室面積 × ペア数
+ リビング面積
+ トイレ・シャワー・洗面・洗濯の面積枠
+ ミニキッチン面積
+ ユニット内動線・清掃収納12%
```

配置に使う必要面積は、さらに次式とする。

```text
配置必要面積 = 1ユニット算定面積 × ユニット数 × (1 + 計画余白率)
```

この面積枠と計画余白は初期計画用であり、確認申請上の最低値ではない。設備数は国内の学生寮事例を踏まえた計画基準で、最終的には茨木市との法規協議と平面図で確定する。

## 6. フロア面積モデル

総階数を `F`、上階1フロア面積を `A` とすると、1階面積 `B` は次式で一意に決まる。

```text
B = 3,600 - A × (F - 1)
```

成立条件:

- `0 < A <= 800`
- `A <= B <= 800`
- 上階の廊下等 = `A × 15%`
- 上階の利用可能面積 = `A × 85%`
- `1ユニット算定面積 × 1フロアのユニット数 × (1 + 計画余白率) <= A × 85%`
- 1階は専有部0㎡、廊下等15%、残り85%を食堂・イベント・管理等の目的共用部とする。

上階利用可能面積のうち、ユニット算定面積に使わない余りも目的共用部へ計上する。計画余白はこの余りの中から確保する配置判定枠で、収支式上の新しい面積区分は作らない。これにより、専有部・目的共用部・廊下等の合計は必ず3,600㎡になり、既存収支表の式も変わらない。

## 7. 全室外周・窓の数値チェック

面積計算だけでは採光可能な平面を証明できないため、探索では外周長の保守的な代理チェックを行う。

- 上階を長辺:短辺 = 2:1の矩形と仮定する。
- 外周の70%をペア室の開口可能外周として扱う。
- 1ペア室あたり2.7mの外壁間口を必要とする。
- `1フロアのペア室数 × 2.7m <= 矩形外周 × 70%` を必須とする。

合格しても、階段・エレベーター・構造・避難経路・隣棟との離隔を配置した実平面の成立までは証明しない。結果表では「外周代理チェック合格」と「平面図未検証」を明記する。

## 8. 収支計算表の再現式

金額単位は万円とする。

```text
躯体工事費 = 3,600㎡ × 25
専有部内装費 = 専有部面積 × 5
目的共用部内装費 = 目的共用部面積 × 12
廊下等内装費 = 廊下等面積 × 6
外構費 = 200㎡ × 6
建設コスト = 上記合計

月間賃料 = ペア室数 × 10
管理費 = 月間賃料 × 10%
月間粗利 = 月間賃料 - 管理費 - 月間運営費300
年間賃料粗利 = 月間粗利 × 12
年間修繕積立 = 建設コスト / RC耐用年数50 / 2
年間利益 = 年間賃料粗利 - 年間修繕積立
回収年数 = 建設コスト / 年間利益
利回り = 年間利益 / 建設コスト × 100
```

まず現行入力（専有2,250㎡、目的共用810㎡、廊下540㎡、112室）が、建設コスト115,410万円、年間利益7,341.9万円、回収約15.72年、利回り約6.3616%を再現することをテストする。

## 9. 最適化と出力

### 9.1 主目的

外周代理・面積・整数配置の必須条件を満たす候補のうち、既存収支表の利回りを最大化する。年間利益最大化と回収年数最小化も併記する。

### 9.2 代表案

少なくとも次の4種を出す。

1. **収支最大案:** 必須条件だけで利回り最大。
2. **推奨バランス案:** ペア室12㎡以上、リビング1人1㎡以上、1階目的共用部1人1㎡以上を満たす中で利回り最大。
3. **小ユニット案:** 4ペア以下の中で利回り最大。
4. **空間ゆとり案:** ペア室14㎡以上、リビング1人1.5㎡以上を満たす中で利回り最大。

1階目的共用部1人あたり面積は、食堂だけでなくイベント・管理等を含む粗い監査指標である。推奨案の条件であって、法令値とは扱わない。

### 9.3 パレート解

次の3指標について、他候補に全面的に劣らない候補を抽出する。

- 利回り: 大きいほど良い
- ペア室面積: 大きいほど良い
- リビング1人あたり面積: 大きいほど良い

CSVにはすべての代表指標と面積内訳を出し、Markdown報告書には代表4案、現行表との比較、注意点を記す。

### 9.4 計画余白の感度分析

- 5%、7.5%、10%を同じ探索範囲で再計算する。
- 各余白率について、成立候補数、推奨バランス案、収支最大案、利回りを比較する。
- CSVは既定10%のパレート解を正本とし、感度比較はMarkdownへ記録する。
- 旧モデルで上階297㎡に対して余り0.002㎡しかなかった案は、10%条件では不成立として扱う。

## 10. 実装境界

### 今回行う

- 純粋な計算関数
- 有限総当たり探索
- 現行表の再現テスト
- 面積保存、整数配置、設備数、外周代理、収支のテスト
- 10%余白の境界値、負の余白率拒否、5%・7.5%・10%感度出力のテスト
- CSVとMarkdownの生成
- ローカルでの再実行手順の記載

### 今回行わない

- Googleスプレッドシートへの書き戻し
- `proposal.html` や既存の未コミット文書の更新
- 平面図・確認申請図の作成
- 法規適合の断定
- 階数による構造・昇降機・防災コストの推計
- 土地込み、借入、税、稼働率、食堂事業を加えた別の事業収支

## 11. 主要な留保

- 既存表は階数割増を持たないため、同じ延床と面積内訳なら高層化の追加費用を評価しない。
- 総延床3,600㎡と容積率300%の関係は、共用廊下等の容積不算入面積を含む用途別検証が必要である。
- 15%の「廊下等」で階段、エレベーター、設備シャフト、防災区画まで成立するかは未検証である。
- 計画余白10%は海外のグロス係数事例を参考にした設計初期の仮定であり、日本の法令値ではない。ペア室12㎡が内法、壁芯、どの測定基準かも平面図段階で固定する必要がある。
- 1階食堂の厨房、席数、時間帯分散、外部利用、管理室等は別途プログラムを詰める必要がある。
- 男女別ユニットの実際の割当比率は需要調査後に決める。計算上は同一寸法のユニットを性別ごとに割り当て可能とみなす。
