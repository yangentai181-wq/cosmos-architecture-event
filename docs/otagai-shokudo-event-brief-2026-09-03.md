# 「お互い食堂」イベント企画書

- 作成日: 2026-09-03
- コンセプト: **「お互いが、留学先」**
- コピー: **一皿ずつ、先生になる。**
- 位置づけ: `docs/community-program-operating-plan-2026-09-03.md` のプログラムCを、コンセプトに沿って具体化する段階実証企画
- 収益上の扱い: 検証中は付帯事業売上へ算入せず、住居の基本収支と会計を分ける

## 企画書1枚

### そのまま載せる要約

> **お互い食堂｜一皿ずつ、先生になる。**
>
> 留学生、日本人学生、地域住民が、言葉・料理・生活知識を一人一つずつ交換する。全員が先生と留学生になる食卓をつくり、学びと次の活動を「お互いパスポート」へ残す。

| 項目 | スライド掲載内容 |
| --- | --- |
| WHY | 混住や交流だけでは既存寮との差にならない。相互の生活支援まで設計する |
| WHO | 居住学生12人＋地域住民6人＋通い型学生・入居検討者6人 |
| HOW | 4チームで調理し、言葉・料理・生活知識を交換する |
| NEXT | 次回の食卓、防災まち歩き、学校活動のいずれかへつなぐ |
| STEP | 居住者内→招待制→24人の外部実証。条件を満たした場合だけ定例化する |
| SUCCESS | 重大事故・未処理苦情0、次の活動への申込30%以上、全費用を記録 |

**事業上の役割:** イベント売上ではなく、継続参加、入居関心、必要な共用空間、地域との関係を検証する。

### 何をするか

留学生、日本人学生、地域住民が4〜6人の混成チームになり、同じ食材を使って、それぞれの家庭・地域・国の料理を一緒につくる。

全員が「教える側」と「学ぶ側」になり、一人一つずつ、次の3点を交換する。

1. 日常で使う言葉
2. 料理または食べ方の知恵
3. 暮らしに役立つ知識

食べて終わるのではなく、交換した内容と次に一緒にすることを「お互いパスポート」へ残す。

### 誰のためか

| 参加者 | このイベントで得る価値 |
| --- | --- |
| 留学生 | 日本語、日本の食文化、買物、ごみ出し、病院等の生活知識を知る |
| 日本人学生 | 語学と異文化コミュニケーションを、授業ではなく共同作業で練習する |
| 地域住民 | 海外の暮らしを知り、学生へ地域の知識を伝える |
| 入居検討者 | 建物見学だけでは分からない、実際の共同生活の雰囲気を体験する |

### 最初の外部実証

| 項目 | 仮設定 |
| --- | --- |
| 定員 | 24人、4チーム×6人 |
| 構成目標 | 居住学生12人、地域住民6人、通い型学生・入居検討者6人 |
| 居住学生の内訳 | 留学生と日本人学生が極端に偏らないよう募集枠を管理する |
| 所要時間 | 150分。昼間開催とし、遅くとも19時までに撤収する |
| 参加方式 | 事前予約制。使用言語、食事制限、撮影可否、緊急連絡先を事前確認する |
| 参加費 | 食材実費を基本仮説とし、金額は原価と価格付き需要調査の後に決める |
| 成果物 | お互いパスポート、レシピ・生活知識カード、次の活動への申込 |

構成と定員は需要の確認結果ではなく、動線・運営を測るための初期仮説である。

### 当日の流れ

| 時間 | 内容 | コンセプトとの接続 |
| ---: | --- | --- |
| 0〜15分 | 受付、手洗い、安全説明、混成チーム編成 | 安心して参加できる境界をつくる |
| 15〜30分 | 「今日交換する言葉・料理・生活知識」を一人一つ決める | 全員を教える側にする |
| 30〜90分 | 4チームで調理する | 言葉だけでなく共同作業から関係をつくる |
| 90〜125分 | 食事と相互インタビュー | 相手の日常を留学経験へ変える |
| 125〜140分 | お互いパスポートを記入・掲示する | 学びを次回へ残す |
| 140〜150分 | 次の食卓・防災まち歩き・学校活動から参加先を選ぶ | 単発で終わらせない |

### 「お互いパスポート」に残すもの

- 今日覚えた言葉と、使う場面
- 同じ食材の異なる使い方
- 南茨木または海外で役立つ生活知識
- 相手の文化を国籍だけで決めつけないために気づいたこと
- 次に一緒にやることと、連絡を仲介する運営担当

個人の連絡先は公開カードへ載せず、継続連絡は運営者が仲介する。

## 3段階の導入

| 段階 | 対象 | 確認すること | 次へ進む条件 |
| --- | --- | --- | --- |
| 1. 居住者内 | 居住学生12人程度 | 衛生、予約、片付け、言語補助、調理台の使い方 | 重大事故0、未処理の苦情0、片付け手順が再現可能 |
| 2. 招待制 | 居住学生＋既知の地域協力者、計18人程度 | 受付、外来者動線、撮影、アレルギー対応 | 居住者専用部への侵入0、継続協力者を確認 |
| 3. 外部実証 | 事前予約24人 | 集客、参加費、入居関心、近隣影響、運営費 | 下記の継続条件を満たした場合だけ定例化を検討 |

一般公開から始めない。食品衛生、保険、施設利用、近隣対応の責任主体を確定できない場合は、前段階へ戻すか中止する。

## 運営体制

| 担当 | 責任 |
| --- | --- |
| 寮運営者 | 総責任、会計、保険、個人情報、事故・苦情対応 |
| 地域コーディネーター | 地域協力者との調整、予約管理、振り返り、次回判断 |
| 学生ホスト4人 | 受付、各チーム進行、言語補助、片付け。任期と報酬を設定する |
| 調理・衛生担当 | 食材管理、手洗い、加熱、アレルギー表示、清掃手順の確認 |
| 連携先 | 地域施設、大学、市・国際交流団体等。協力内容は合意後だけ公表する |

学生ホストへ、企画、翻訳、買出し、当日運営、片付けを無償で当然に求めない。

## 安全条件

- 開催前に、提供方法に応じた営業許可・届出の要否を保健所等へ確認する。
- 食物アレルギー、宗教・信条上の食事制限を事前取得し、完全除去を保証できない場合は明示する。
- 初期実証では生もの、酒類、持込み手料理を扱わない。
- 未成年者を招く場合は、保護者同意と責任ある団体の同席を別途条件にする。
- 撮影可否を受付で識別し、氏名、部屋番号、個人連絡先を公開しない。
- 地域利用者は、住居を通らず公開ゾーンへ出入りする。
- 終了時刻、騒音、ごみ、駐輪、退場確認の担当を決める。

## 空間へ返す条件

- 4チームが同時に作業できる可動テーブルと調理設備
- 受付、手洗い、食材仮置き、配膳、食事、片付けが逆流しない動線
- 外部から直接入れる入口と、居住者専用部を施錠できる境界
- お互いパスポートを蓄積して見せる掲示面
- ごみ・清掃用具・食材を分けて保管できる収納
- 24人の実証で、音、滞留、荷物、換気、片付け時間を測ってから必要面積を決める

## 記録する費用

- 食材、消耗品、会場、保険、清掃、ごみ処理
- 企画、連携交渉、広報、翻訳、買出し、当日運営、片付け、会計の人件費
- 参加者1人当たりの総費用と、学生・運営者の総稼働時間
- 参加費、協賛、助成は別記し、入金が確定した金額だけ記録する

住居の採算は家賃で成立させる。「お互い食堂」は、継続参加と入居関心を検証する費用として評価する。

## 定例化の暫定判断条件

以下は市場標準ではなく、初期の過大運営を避けるための本案件用ルール案である。

- 予約者の80%以上が当日参加する
- 留学生、日本人学生、地域住民・通い型学生のいずれか一方だけに極端に偏らない
- 参加者の30%以上が、次回または別の共同活動へ申し込む
- 重大事故、個人情報事故、居住者専用部への無断立入りが0件
- 未処理の近隣苦情が0件
- 学生を含む全員の人件費と外部支出を記録できる
- 運営者と協力者を次回も確保できる

条件を満たさない場合は、月例化せず、人数、公開範囲、内容、頻度のいずれかを縮小する。

## 発表用の一言

> 「お互い食堂」は、世界の料理を食べるイベントではありません。一人一つ、言葉・料理・生活知識を交換し、全員が先生と留学生になる食卓です。まず居住者内で安全と運営を検証し、招待制を経て地域へ開きます。売上ではなく、次の関係が生まれたかを成果にします。
