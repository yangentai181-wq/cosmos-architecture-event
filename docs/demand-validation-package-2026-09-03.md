# 国内留学型学生寮 需要検証パッケージ

- 基準日: 2026年9月3日
- 対象: 私立文系の大学生を中心とする通い型・短期滞在型・下宿型
- 対象地: 大阪府茨木市東奈良三丁目、南茨木駅徒歩圏
- 目的: 公表統計から、調査、予約行動、収支、建築配分までを一つの判断手順につなぐ
- 位置づけ: 実需調査前の設計資料。未検証率は予測ではなく、調査で置き換える仮定

> **更新注記（2026年9月4日）:** 本文の100ペア室・200人案は旧比較であり、現在の設計方針ではない。現在は168室を収支上限、寄宿舎91室・共同住宅99戸を行政確認前比較、7個室Unit 84室を配置前比較として扱う。最新の価格帯と需要ゲートは `docs/price-positioning-and-demand-gate-2026-09-04.md`、設計・収支の判断は `docs/day2-closeout-2026-09-04.md` を優先する。

## 1. 判断要約

1. **需要調査を進める価値はある。** 2022年度の居住形態別絶対数を基に、京阪神の私立文系は約17.1万人、自宅生約12.0万人、寮・下宿生約5.1万人と推計できる。現在の申込者数ではない。
2. **主な家賃収入は下宿型で作る。** 通い型は母数が大きいが、イベント参加・短期体験・将来入居への入口として扱う。
3. **南茨木の学生住宅市場は動いているが、一様な満室市場ではない。** 139室の新築物件や複数の近隣物件が満室表示である一方、空室を掲載する物件もある。
4. **「混住」「国際交流」だけでは差別化できない。** 徒歩圏に立命館OICの国際寮が合計369室あり、いずれも個室型である。
5. **低層優先と高利回りは現状では両立していない。** 住戸面積に10%の計画余白を置く5階バランス案は100ペア室、建設費12億2,410万円。土地7億円、稼働率95%、1室月10万円では土地込み利回り2.83%、回収35.4年である。
6. **目標利回り7%に必要な賃料は、5階案で1ペア室月約17.83万円、1人約8.91万円。** 食費・光熱・ネット等を含まないため、2人寝室のまま市場に受け入れられるかが最大の未検証事項になる。

### 採用・不採用

- **採用する既存パターン:** 個室または退避可能な私的空間、小ユニット、RA/RM、食費等を含む総額表示、通い・短期・長期の分離。
- **そのまま採用しない:** 大学直営寮の低価格。大学補助と募集基盤があり、民間事業の収支条件が違う。
- **検証せず採用しない:** 2人寝室を全室標準にする案。周辺の主要国際寮は個室型で、一般的な受容性を示す公表値がない。
- **新規実装した部分:** 需要獲得率と土地代込み収支を同じ画面で変える計算モデル。ローカルおよび接続GitHubに同目的の資産がなかったため、既存の住戸最適化式へ薄く追加した。

## 4. 需要人数モデル

### 下宿型

初期仮定:

- 京阪神私立文系の下宿母数: 50,928人
- 4学年で均等に更新: 年12,732人
- 南茨木で狙える範囲: 50% → 年6,366人
- 認知率30% × 条件付き関心率25% × 申込率40% × 予約金支払率80%
- 予約金支払い見込み: 152.8人
- 国内学生100人枠に対する充足倍率: 1.53倍

これは需要予測ではない。初期仮定では、南茨木で狙える年間母数の1.57%が予約金を支払えば100人へ届く。以下の実査で、各率を上流から順に置き換える。

### 通い型

初期仮定:

- 自宅生母数120,337人 × 南茨木で狙える割合40% = 48,135人
- 募集接触5% → 初回有料参加10% → 2回目参加30%
- 初回有料参加: 約241人
- 反復参加: 約72人

通い型の空間規模は初回参加者ではなく、同時利用者数と2回目参加者数で決める。

計算は [需要・収支検証モデル](../validation/index.html) で変更できる。

4. 予約前に必要な証拠: 費用明細、管理体制、現地見学、体験宿泊、大学連携、第三者評価。

## 7. 6〜8週間の実証

### 実行順

1. **第1〜2週: 募集ページの閲覧テスト**

   通い、短期、下宿を別の選択として提示し、対象者別の到達と回答開始を測る。
2. **第2〜4週: 有料の通い型体験**

   南茨木周辺の既存会場で20〜40人規模。会話だけでなく、食、留学準備、防災の4テーマを比較する。
3. **第4〜6週: 1〜2週間の短期滞在予約テスト**

   宿泊施設の手配は別途必要。募集ページでは価格別の予約意思まで測り、契約前に止める。
4. **第5〜8週: 下宿型の返金可能な予約金テスト**

   部屋条件、月額総額、開業条件、返金条件を契約文案で明示する。実際の受領は法務・決済・返金体制と承認後。

| 段階 | 指標 | 意味 |

### 内部判断ゲート

以下は市場標準ではなく、過大投資を避けるための本案件用ルール案である。

| 結果 | 判断 |
|---|---|
| 予約金意思25人未満 | 長期入居を中核にせず、コンセプトと価格を再設計 |

| **合計** | **615㎡** | 端数調整前 |

可変余白を残すことで、通い型の反復参加が弱い場合にも、共用部が過大な固定資産になるのを避ける。

### 居室の運用

- 初期仮説: 長期92ペア室＋可変8ペア室。
- 可変8室は最大16人の短期滞在、長期入居者の部屋変更、欠員調整に使う。
- 短期需要が弱ければ長期へ戻し、短期専用の設備仕様は増やさない。
- 2人寝室の受容性が確認できなければ、個室ユニット型へ戻して戸数・収支を再計算する。
