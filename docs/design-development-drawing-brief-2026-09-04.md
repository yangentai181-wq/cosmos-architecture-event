# 次段階の図面ブリーフ｜B1/B2を同じ条件で比較する

- 作成日: 2026-09-04
- 対象: B「角の交流核」の配置・1階平面・外観・外構
- 目的: 概念図を、行政・運営・近隣条件を確認できる図面へ進める
- 状態: **設計者への作図指示**。筆界、道路、用途、階数、室数、材料を確定するものではない
- 判定表: 共有Sheet「図面受入基準_0904」
- 更新優先: `docs/spatial-massing-deep-dive-2026-09-04.md` の同一84室・5・6・7階比較を先に行う

## 結論

まず5・6・7階 × B1/B2を、同じ敷地図、同じ縮尺、84室、公開・緩衝165㎡、同じ駐車・駐輪条件で6セルの粗い配置比較にする。そこで自動不合格条件を踏んだ枝を落とし、残った枝だけを本書の詳細図面へ進める。

B1交差点寄りとB2道路中央は、見栄えではなく、**外部利用者、居住者、搬入・ごみ、避難・消防の四つを交差させず、公開部だけを閉鎖できるか**で比較する。7階はユニットを整数配置できるため最初に描くが、優位案ではない。

行政回答前は、寸法の根拠がない完成平面や、建築面積いっぱいの形を描かない。未確認条件は図面上で「未確認」と表示し、空欄を推測で埋めない。

## 0. Phase 0｜5・6・7階 × B1/B2の6セル

### 六セルで固定する入力

| 入力 | 共通条件 |
| --- | --- |
| 居住 | 84個室、7個室ユニット×12組 |
| 容積対象床 | 3,000㎡。敷地全体へ容積率300%を適用できるという行政回答前の仮定 |
| 公開・緩衝 | 165㎡。目的共用部の内訳であり追加床ではない |
| 駐車・駐輪 | 自動車17台、駐輪84台を同じ区画条件で表示。緩和枝は別表にする |
| 比較位置 | B1交差点寄り / B2道路中央 |
| 必須表示 | 最大投影面積、基本空地候補、車路・転回、消防、ごみ、三入口、四動線、前庭残余 |

6セルは完成平面ではなく、比較条件を混ぜないためのブロック図とする。各セルに `○ / △ / × / 未確認`、不合格理由、次に必要な証拠を書く。単純な `1,000㎡−3,000㎡÷階数` を使える外構面積とは呼ばない。

### 詳細図面へ残す条件

1. 最大投影面積を使っても基本空地、車路・転回、消防、ごみ、前庭を二重計上していない。
2. 外部利用者が居住入口、エレベーター、メール、個室階を通らない。
3. 17台の平置き駐車と前庭を、車路なしで同じ場所へ重ねていない。
4. 5・6・7階で室数、公開床、駐車・駐輪条件を変えていない。
5. 階数別の構造・設備・避難・管理負担を0円または同額とみなしていない。

7階は最初に反証し、続けて5階、6階を同じ粒度で描く。6セルのうち優位未確定のまま残った枝が複数あれば、複数のまま次の六図面へ進める。

## 3. 受入れ前の20項目

### 敷地・外構

1. 使用した敷地図の出典、作成日、縮尺、北、寸法の根拠が書かれている。
2. 確定筆界と推定線を描き分け、対象地面積をCADの閉じた線から再取得している。
3. 二つの道路の種別、有効幅員、後退、隅切り、水路条件、基本空地1.0m／1.5mの判定を回答元とともに示している。
4. 車両乗入れ、消防・救急、短時間搬入、ごみ回収が同じ図で確認できる。
5. 居住者用と来場者用の駐輪を分け、法定・協議台数とラック等の形式を示している。
6. 24人イベント時の受付列、傘、荷物、車椅子・ベビーカー、退出が通行を塞がない。

### ゾーニング・動線

7. 公開＋緩衝165㎡の内訳が合計し、135〜200㎡の検証幅と区別されている。
8. 公開入口、居住者入口、搬入・管理入口の三つを識別できる。
9. 外部利用者、居住者、搬入・ごみ、避難・消防の四動線を線種付きで追える。
10. イベント不参加の居住者が受付列、撮影、音、においを通らず帰宅できる。
11. 受付から公開範囲と施錠境界を確認でき、迷っても居住部へ進めない。
12. 終了後に公開交流棟だけを閉鎖し、居住入口、宅配、縦動線を継続できる。

### 建築・近隣

13. 受付、ラウンジ、キッチン、手洗い・トイレ、管理・収納・清掃の隣接関係が読める。
14. 壁、柱、階段、エレベーター、設備シャフト、用途区画、避難を面積から控除している。
15. 隣接住宅の窓、バルコニー、入口、設備、ごみ、夜間照明を立面・断面で比較している。
16. 公開部の透明面から、居住者の顔、部屋番号、郵便、帰宅動線を直接見せない。
17. 街路側立面に、イベント中と終了後の建具、サイン、照明、家具の違いがある。
18. 公開部、前庭、サイン、居住者入口、居住棟の照明回路を分けている。

### 数字・比較条件

19. B1/B2で公開床、室数枝、駐車・駐輪、イベント定員、評価尺度を同じにしている。
20. 寄宿舎84/91室、共同住宅99戸、収支上限168室を同じ「案」として混ぜず、採用・比較・不成立を明記している。

## 4. 自動で不合格にする条件

次のどれかがある図面は、見た目が整っていても比較へ進めない。

- 未確認の道路幅員、筆界、用途地域境界、乗入れ位置を確定値として描く
- B1とB2で室数、公開床、駐車条件、イベント定員のどれかを変える
- 公開165㎡を目的共用810㎡へ追加し、総床を増やす
- 168室を法規・実配置の成立案として表示する
- 居住者が外部受付またはイベント空間を通らないと帰宅できない
- 公開部を閉じると居住入口、宅配、避難、設備管理も止まる
- 24人の実証前に大会場、常設食堂、月例運営を前提に面積を増やす

## 5. 図面に残す未確認ラベル

以下は回答が出るまで、図面の注記欄へ明示する。

- 筆界・対象地面積・用途地域境界
- 道路種別・幅員・隅切り・後退・乗入れ・基本空地
- 用途区分、容積不算入、駐車・駐輪、消防活動の扱い
- 隣接住宅の開口・設備・夜間利用と冬至日日影
- イベントの責任主体、定員、営業時間、消灯、搬入、清掃、ごみ
- 外装材、ガラス、建具、サイン、照度、植栽の仕様と維持費

## 6. 判定方法

1. 20項目をB1/B2それぞれ `○ / △ / × / 未確認` で評価する。
2. `×`が1件でもあれば不採用または再作図、`未確認`が1件でもあれば保留とする。
3. `△`は、修正内容、担当、期限を同じ行に記録する。
4. 20項目がすべて`○`になっても、行政・近隣・運営の合意を意味しない。次は面積・収支の再計算へ進む。
