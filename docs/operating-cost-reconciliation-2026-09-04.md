# 運営コストの分母・重複整理

- 作成日: 2026年9月4日
- 対象: 「スイジャー管理約2%」「建物全体15〜20%」「食堂等10〜15%」という会議メモ
- 状態: **原典・見積未確認の感度分析**
- 使用モデル: `validation/model.mjs`

## 結論

三つの割合は、現時点では同じ式へ足さない。

理由は、分母が「賃料収入」「売上」「運営原価」「建設費」のどれか不明で、管理受託、建物維持管理、食堂運営の費目も重複し得るためである。公式の学生寮運営事業者の案内でも、入居者対応、警備、食事、清掃、保守、小修繕などは一括・個別の両方で受託される。割合だけでは範囲を決められない。

「スイジャー」という表記に一致する学生寮運営者・料金表は、今回の公開情報検索では確認できなかった。社名または発言者メモの原文を確認するまで、固有名詞として外部資料へ載せない。

## 共同住宅99戸の比較値で金額へ直す

比較条件は、99戸、月額10万円、稼働率95%、実効年間賃料1億1,286万円、建設費11億3,610万円、土地費7億円、年間修繕引当1,136.1万円である。これは茨木市回答前の法規比較値であり、成立済み住戸数ではない。

| 表現 | 同じ分母を実効年間賃料と仮定した額 | 現時点の扱い |
| --- | ---: | --- |
| 管理約2% | 225.7万円/年 | 管理受託料だけを指す可能性。業務範囲を確認 |
| 現行管理10% | 1,128.6万円/年 | 現行モデルの入力 |
| 建物全体15% | 1,692.9万円/年 | 包括運営費の下限という仮説 |
| 建物全体20% | 2,257.2万円/年 | 包括運営費の上限という仮説 |
| 現行固定運営費 | 3,600万円/年 | 実効賃料の31.9%。内訳未確認 |

現行モデルは、管理10%と固定運営費3,600万円を両方控除している。修繕引当前で4,728.6万円、実効賃料の41.9%に相当する。修繕引当まで含めると5,864.7万円、52.0%である。

## 重複しない四つの読み方

| 読み方 | 年間利益 | 土地込み利回り | 回収 | 7%に必要な月額/室 |
| --- | ---: | ---: | ---: | ---: |
| 現行: 管理10%＋固定3,600万円＋修繕 | 5,421.3万円 | 2.95% | 33.9年 | 17万3,162円 |
| 2%が管理料を置換、固定費と修繕は維持 | 6,324.2万円 | 3.44% | 29.0年 | 15万9,027円 |
| 15%が管理＋固定費を置換、修繕は別 | 8,457.0万円 | **4.61%** | 21.7年 | 14万5,821円 |
| 20%が管理＋固定費を置換、修繕は別 | 7,892.7万円 | **4.30%** | 23.3年 | 15万4,935円 |

もっとも楽観的な「15%が管理＋固定費をすべて置き換える」読み方でも、土地込み7%へ届かない。したがって、割合の確認は必要だが、確認結果だけで現行事業条件が成立するとは見込まない。

食堂等10〜15%は、食堂売上・食材原価・人件費のどれを分母または対象にするか不明である。現在の付帯事業売上・利益は0円なので、寮室料へ便宜的に掛けず、食堂の独立損益ができるまで算入を保留する。

## 見積依頼で揃える項目

| 確認項目 | 必須の回答 |
| --- | --- |
| 正式名称 | 「スイジャー」の会社名・サービス名・資料名 |
| 分母 | 総賃料、実効賃料、総売上、建設費、定額のどれか |
| 2%の業務 | 募集、契約、収納、夜間対応、RA、イベント、清掃、設備保守の包含 |
| 15〜20%の業務 | 2%との包含・除外、税、保険、修繕、広告、空室損の包含 |
| 食堂10〜15% | 売上歩合か、原価率か、管理委託料か。食材・人件費・光熱費の包含 |
| 最低保証 | 最低月額、最低人員、物価・人件費連動、契約期間、解約費 |
| 売上帰属 | 家賃、管理費、食費、イベント参加費、テナント賃料の受取主体 |
| リスク負担 | 空室、食数不足、食材高騰、事故、修繕、未収金を誰が負担するか |

## 収支へ入れる順序

1. 業務一覧を一行ずつ分ける。
2. 各費目を「定額」「売上歩合」「実費」「投資額連動」に分類する。
3. 同じ業務の二重計上を消す。
4. 食堂は寮賃料と分けた独立損益にする。
5. 税、保険、募集、空室、修繕、金融費用を追加して再計算する。
6. 事業者見積の税込・税抜、対象年、最低保証を揃えて比較する。
