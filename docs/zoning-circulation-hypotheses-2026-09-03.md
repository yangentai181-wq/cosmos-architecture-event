# 公開・居住ゾーン配置と動線の比較仮説

- 作成日: 2026-09-03
- 更新日: 2026-09-04
- 対象: 「お互いが、留学先」を空間へ落とす初期検討
- 状態: **未確定の比較案**。平面計画、敷地境界、接道、法規、騒音、事業収支の確認前に固定しない
- 比較図: `docs/public-private-zoning-options.html`

## 結論

現時点では、**B「角の交流核」**を次の検討へ進める第一仮説とする。

街・駅から近づく角に公開ゾーンを小さく置き、管理・衛生・収納等の緩衝ゾーンを挟んで、居住者専用部を敷地の奥へまとめる。外部利用者と居住者の入口を分け、イベントへ参加しない居住者も公開空間を通らず帰宅できる構成である。

これは採用案ではない。接道可能な位置と主要な歩行者流が分かれば、「角」が別の場所になる可能性がある。

2026-09-04の検討では、B案を外観・建物形状・外構へ展開する第一仮説として承認した。低い公開交流棟と前庭を街角へ置き、5階の居住棟をその奥または上階から後退させる。詳細は `docs/open-corner-architecture-design-2026-09-04.md`、図版は `assets/open-corner-design.svg` を参照する。

## 比較した3案

| 案 | 構成 | 強み | 主な負担 | 現時点の判断 |
| --- | --- | --- | --- | --- |
| A 街路沿いの公開帯 | 街路側へ公開空間を帯状に並べ、奥を居住とする | 活動が街から見え、開放性を表現しやすい | 公開床と外部接点が増え、警備・清掃・騒音対策が重くなる | 需要実証後の拡張候補 |
| B 角の交流核 | 街側の一角へ公開機能を集約し、緩衝帯で居住と分ける | 小さく始められ、入口・閉鎖・管理範囲を明確にしやすい | イベント時の受付滞留と、一か所への集中を処理する必要がある | **第一仮説** |
| C 中庭まで開く | 公開動線を建物内部の中庭まで引き込む | 国際交流への開放を建築の中心として表現できる | 外来者が居住部へ近づき、防犯・夜間静穏・避難の調整が難しい | 初期案では採用しない |

## B案の動線原則

### 外部利用者

```text
街・駅側
  → 前庭・軒下
  → 公開入口
  → 受付・手洗い
  → 交流キッチン／可変ラウンジ
  → 同じ入口から退出
```

外部利用者は、居住者用エレベーター、階段、郵便、宅配、個室階を通らない。

### 居住者

```text
街・駅側
  → 居住者専用入口
  → 入退室管理
  → 居住者用縦動線
  → 各ユニット・個室
```

イベントへ参加しない居住者が、外部利用者の受付列や交流空間を通らず帰宅できるようにする。

### 運営・搬入

```text
搬入可能な接道側
  → 短時間搬入
  → 施錠できる収納・ごみ仮置き
  → 交流キッチン
```

参加者の入口と交差させず、食材、ごみ、清掃、イベント機材を居住者用動線へ流さない。搬入位置は道路種別と乗入れ可否を確認してから決める。

## 3層の役割

### 公開ゾーン

- 前庭・軒下、受付、交流キッチン、可動机・椅子、バリアフリートイレ
- 防災まち歩きの地図整理、学校活動の準備、「お互い食堂」の少人数実証に転用する
- イベント終了後は、公開ゾーンだけを閉鎖できる

### 緩衝・管理ゾーン

- 管理・相談、手洗い、収納、清掃、ごみ、必要に応じた防音前室
- 外部利用者が居住部へ迷い込まない境界をつくる
- 活動を外から見せつつ、居住者の顔、部屋、帰宅動線を見せない

### 居住者専用ゾーン

- 居住者用入口、縦動線、個室、ユニット内共有リビング
- ユニット内共有リビングは地域開放せず、居住者の日常的な相互学習に限定する
- 公開イベントを実施しない日も、居住機能が独立して成立する

## 現時点で固定しないもの

- 公開入口・居住者入口・搬入口の正確な位置
- 建物の形、高さ、階数、外壁線、各ゾーンの面積
- 公開ゾーンを街路のどの辺へ向けるか
- 厨房の営業形態、調理設備、席数
- 前庭、広場、植栽、水路との関係
- 駐輪・駐車、消防活動空地、避難経路
- 住宅戸数、個室・2人室の構成

既存の住戸最適化案は、12階前後・2人寝室を主とする算術案であり、最新方針の6階未満優先と、個室性を重視する検討に一致しない。そのため、今回の配置根拠には採用しない。

## 次の確定条件

1. 確定筆界、道路種別、有効幅員、歩行者・車両の乗入れ可能位置を確認する。
2. 駅・OIC・地域施設からの実際の歩行者流と、夜間の帰宅経路を確認する。
3. 敷地各辺の昼夜の騒音と、隣接マンションの窓・入口・ごみ・搬入位置を測る。
4. 24人程度の既存施設実証で、受付滞留、必要席数、音、荷物、片付け、運営人数を記録する。
5. 6階未満の複数案で、住宅戸数、公開・緩衝床、建設費、土地代込み収益を比較する。
6. 避難、防火、バリアフリー、食品衛生、近隣対応を専門家・行政へ確認する。

上記のうち、接道、避難、収支のいずれかが成立しなければB案も採用せず、公開範囲または建物構成を戻して比較する。
