# 地域へ還元できるイベントの実例調査

- 調査日: 2026年9月3日
- 目的: `docs/current-direction-2026-09-03.md` 第11節「イベント活用の観点から企画内容を明日までに詳細化する」に対応する
- 方針: 「やれそうな案」ではなく、**実在の寮・大学・地域団体が実際に開催しているイベント**のみを、主催者・場所・内容・費用の分かる範囲で記録する
- 収益への扱い: どのイベントも、売上・経費・人件費・開催頻度・責任主体が確認できるまで収益計画には算入しない

## 1. 実例一覧

### A. 防災を入口にした地域交流

| 項目 | 内容 |
|---|---|
| 名称 | 第4回 おもろい学（あそ）び場 グローバルビレッジフェス |
| 場所 | 大阪大学グローバルビレッジ津雲台（吹田市津雲台5丁目）＝混住型国際学生寮の敷地内 |
| 日時 | 2024年11月10日(日) 10:00〜14:00（第3回は2023年11月19日。**年1回・秋の定例**） |
| 内容 | 「防災まち歩き×防災訓練VR体験」。寮敷地内のポイントを巡りながら防災アプリ「災救マップ」の使い方を体験。所要約40分、入退場自由、景品交換あり |
| 共催・協力 | 大阪大学医学部附属病院 高度救命救急センター、プライム ライフ テクノロジーズ株式会社、一般社団法人 地域情報共創センター |
| 参加費 | 無料 |
| 南茨木への含意 | **寮が地域に対して最初に提供できる価値は「防災」**。企業・病院・地域団体が共催に入ることで、寮単独ではなく外部リソースで運営が回っている。イベント名も「学び場」であって「国際交流」ではない点が重要 |

### B. 居住者と近隣住民が混ざる文化フェスティバル

- **東京国際交流館（JASSO・お台場）の「国際交流フェスティバル」**：留学生・研究者宿舎の入居者と近隣住民等が各国の文化に触れ交流する。同館は他に、入居者が研究成果を発表する**交流研究発表会**、日本文化を学ぶ**国際塾**、**国際シンポジウム**、**フォトコンテスト**を実施している。
- 含意: 一つの大型フェスに集約せず、**「発表」「学ぶ」「見せる」「集まる」を別イベントに分けて年間で並べている**。フォトコンテストのように会場も人件費もほぼ不要な形式が混ざっている点は、運営費を抑える設計として参考になる。

### C. 大学キャンパスの地域開放イベント（茨木市の既存事例）

| 項目 | 内容 |
|---|---|
| 名称 | いばらき×立命館DAY |
| 主催 | 立命館大学主催・**茨木市共催**。OIC開設当初から継続 |
| 場所 | 立命館大学 大阪いばらきキャンパス および 岩倉公園 |
| 直近 | 2026年5月17日(日)に「いばらき×立命館DAY 2026」を開催 |
| 内容 | 学生・教員に加え、**行政、企業、市民団体が企画やブースを出展**し、日々の成果を地域に発信する地域開放型イベント |
| 関連施設 | 立命館いばらきフューチャープラザ＝茨木市との公私協力で整備された地域・社会連携のシンボル施設 |
| 南茨木への含意 | **茨木市には既に「大学×市」の年次イベントの受け皿がある**。寮が独自イベントを立ち上げるより、ここに出展・参加する側から始めるほうが、実績も接点も早く得られる |

### D. 日本語・語学を介した交流（茨木市内の既存の受け皿）

**茨木市国際親善都市協会**（茨木市駅前3丁目、市文化振興課内）の年間事業:

- 英語スピーチ大会（6月ごろ）
- 「国際交流の集い」（10月）
- 日本語スピーチコンテスト（11月・1月）
- **実用日本語学習会**：日本語を母語としない人へ**マンツーマン**で学習支援
- **ホストファミリー募集／大阪大学留学生向けホストファミリープログラム**
- 姉妹友好都市（ミネアポリス市、安慶市、小豆島町、竹田市）との市民訪問団

含意: 「留学生に日本語を教える」「スピーチコンテスト」は**市側に既存プログラムがある**。寮が同じものを作ると重複する。寮は**会場と参加者を提供する側**に回るのが現実的。

### E. 小中学校への出前・国際理解教育

- 京都市立梅小路小学校では、6年生の外国語学習として**9か国18名の留学生**が参加し、児童が英語でインタビュー、抹茶でのおもてなしを行う交流を実施（龍谷大学の地域連携事例）。
- ABIC（国際社会貢献センター）は小中高への**国際理解教室の講師派遣**を事業化している。
- 含意: **留学生を「教える人」として学校へ送り出す**形式。寮の側に必要なのは会場ではなく**人の名簿とコーディネート**だけで、初期投資がほぼ要らない。地域還元の実績を最も早く作れる型。

### F. 日常の食・生活の共有（寮内→地域へ）

- 静岡県立大学の国際学生寮「富学寮」では、交流スペースで日本人学生と留学生が**各国の料理を作りあい、互いの言語を教えあい、地域の人とも交流**している。
- コンセプト「お互いが、留学先」に最も近い形式。留学生が生活知（行政手続き・病院・ごみ出し）を受け取り、日本人学生が語学を練習するという相互性が、そのまま**地域住民を第三の参加者**として招く形に拡張できる。

### G. 外国ルーツの子どもへの学習支援

- 認定NPO法人 多文化共生センター東京、東京YWCA「いちごの部屋」等が、外国にルーツを持つ子どもの**日本語・学習支援**を実施。愛知県の二言語学習室「にじいろ寺子屋」、浜松の多文化子ども支援センター等、自治体連携の事例が総務省・CLAIRの事例集に集約されている。
- 含意: 週次で回る**継続型**の活動であり、単発フェスと違って寮の共用室が平日夕方に稼働する。ただし担い手の継続性と子どもの安全管理の責任主体が要る。

### H. 空間側の仕掛け（イベントを支える設計）

グローバルビレッジ津雲台の設計（類設計室）:

- **柵を設けない**。「誰もが気軽に訪れることができる環境をつくることで地域との一体化を促進」
- ニュータウン以前からのメタセコイアや桜並木など**既存の植生を敷地内に取り込む**
- **3つの広場**（グローバルコート、コミュニティーガーデン、九十九坂テラス）に集い・交流・発信できるシェア空間を点在させ、内外一体の賑わいをつくる

含意: 現行方針の「ピンクゾーン＝開かれた空間／グリーンゾーン＝居住者専用」の分け方に対し、**囲わずにゾーニングする**手法が実例として存在する。低層案への再検討とも整合する。

## 3. 南茨木案への適用（提案）

1. **開業初年度は「防災」と「小中学校への留学生派遣」の2本に絞る。** どちらも初期費用がほぼ不要で、隣接住宅・病院への配慮（`docs/site-surroundings-current-analysis.md` のThreat）に直接応え、寮が地域にとって迷惑施設ではないことを最初に示せる。
2. **茨木市の既存プログラムに乗る。** 茨木市国際親善都市協会（日本語学習会・ホストファミリー・スピーチ大会）と、いばらき×立命館DAY（市共催・岩倉公園）は既に稼働している。寮は新規に立ち上げるのではなく、**会場・参加者・運営人手を出す側**として入る。
3. **共催者を最初から設計に入れる。** 阪大津雲台のフェスは病院・企業・一般社団法人が共催で成立している。寮単独運営を前提にすると人件費が跳ね上がる。
4. **「国際交流」を看板にしない。** 実例で人が集まっているのは防災・食・子どもの学びであり、国際交流はその結果として起きている。イベント名は地域住民の関心語（防災・こども・食）で立てる。
5. **収益に載せない。** 現行の収益シートは付帯事業売上0円で計算しており、この扱いを維持する。イベントは**費用側**（共用部の面積・運営人件費）として計上し、共催・助成で相殺する構造を書く。
