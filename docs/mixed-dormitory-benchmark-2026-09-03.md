# 近接コンセプト寮のベンチマーク調査（混住型・国内留学型）

- 調査日: 2026年9月3日
- 対象コンセプト: 留学生と日本人学生が混住し、「国内留学」的な環境を日常でつくる寮（`docs/current-direction-2026-09-03.md` 第4節）
- 目的: 同種コンセプトの既存プランがどう作られ、いくらで、どう運営されているかを把握し、南茨木案の差別化点と検証すべき論点を特定する
- 注意: すべて公開情報。金額・室数は各運営主体の公表値であり、南茨木での需要・収益を証明する資料ではない

## 結論（先に3点）

1. **「混住」自体はすでに標準装備である。** 大学系（阪大・関大・関学・明治・立命館）は混住型国際寮を持ち、南茨木の徒歩圏には立命館OICのIハウス・グローバルハウスが実在する。「留学生と日本人が一緒に住む」だけでは差別化にならない。
2. **差がつくのは「単位の設計」と「運営制度」である。** 成功事例に共通するのは、①5〜9人程度のユニット（生活の最小単位）②各ユニットに配置されたRA/RM/RT ③フォーマル（プログラム）とインフォーマル（日常）の組み合わせ、の3点。住総研の研究論文も、居住単位のまとまりと階層関係、およびRAによる参加誘導を要件として挙げている。
3. **価格帯は2層に割れている。** 大学系混住ユニット型は月4.5万〜6.5万円（阪大津雲台のユニット5.9万円前後、関大南千里5.3万円、立命館Iハウス6.42万円）。民間の食事付き学生会館・個室は月7万円前後（立命館グローバルハウス7.42万円、南茨木のコスモグラシア5.45万〜7.13万円）。**民間事業として建てる南茨木案は、大学寮の価格に正面から張り合えない**ため、価格ではなく「大学寮に入れない層／大学寮にない機能」で立つ必要がある。

## 2. 型の分類（南茨木案がどこに立つか）

| 型 | 代表 | 建設・所有 | 収入源 | 南茨木案との距離 |
|---|---|---|---|---|
| A 大学直営型 | 阪大津雲台、関大、立命館 | 大学（＋PFI・民間連携） | 大学予算＋寮費（相場より安い） | 価格で競合できない。**入居対象から漏れる層**が南茨木の顧客 |
| B 民間所有・大学連携型 | 明治GV（共立メンテナンス所有・運営） | 民間 | 寮費。大学が入居者を送る | **最も事業モデルが近い**。大学連携が成立するかが分岐点 |
| C 公益法人・NPO型 | 京都国際学生の家 | 財団 | 寮費＋助成＋寄付 | 地域交流・低家賃の根拠になるが、助成依存で収益計画には算入しづらい |
| D 民間シェアハウス型 | ボーダレスハウス、チェルシーハウス | 民間 | 家賃＋共益費 | **大学に依存せず「国際比率」と「運営」だけで成立している唯一の型**。比率管理・審査・プログラムの運用ノウハウが直接参考になる |

南茨木案は所有形態としてはB/Dである。Bを取るなら立命館との連携が事実上の前提条件になり、Dを取るなら「大学が送客しなくても留学生と日本人が半々で埋まる」ことを自力で示す必要がある。

## 3. 事例から抽出した設計要件

### 空間

- **ユニットの人数は5〜9人**（阪大5/7/9人、関大6〜7室、立命館Iハウス6室、明治6室）。この帯が実務上の共通解になっている。10室を超える共用単位は事例に見当たらない。
- **個室＋共用ユニット**が主流。相部屋（2人室）を前提にしているのは大学系混住寮ではむしろ少数派で、阪大・関大・立命館・明治はいずれも**個室ユニット**である。方針文書の「2人入居で家賃を下げる」仮説は、事例側からは支持されない。
- 住総研の研究は、居住単位のまとまりと階層関係（個室→ユニット→フロア→棟）を学びの成立要件として挙げている。

### 運営

- **各ユニットに1名の学生スタッフ**（RA／RM／RT）。立命館Iハウスは各ユニット原則1名、役割は生活支援・寮運営・衛生管理・行政手続き・日本語学習サポート・イベント企画まで及ぶ。人件費・採用・研修は収益計画に必ず載る項目。
- **異文化交流は自然発生しない**（住総研・JASSO『留学交流』ともに指摘）。環境と制度の設計が必要で、フォーマルなプログラムとインフォーマルな日常の両方を組み合わせることが要件とされる。
- **言語の運用ルール**：阪大津雲台は混住ユニットの日常会話を英語と明示している。「英語が使える」ではなく「英語で運用する」と決めた事例がある点は、南茨木案の価値提示に直結する。
- **比率の管理**：ボーダレスハウスは日本人:外国人=50:50を運営ルールとして維持している。混住は放置すると偏るため、募集段階での枠管理が要る。
- **契約の柔軟性**：チェルシーハウスは更新料・違約金を取らず、留学・休学・転学で退去しても不利にならない設計にしている。留学生の在留期間が短い（立命館Iハウスは原則1年、阪大は留学生最長24か月）ことを踏まえると、**回転率の高さを前提にした契約・原状回復・募集コスト**の設計が必須。

## 4. 南茨木案への示唆

1. **競合は「南茨木のコスモグラシア」だけではなく「立命館OICのIハウス／グローバルハウス」である。** 徒歩圏に369室（168＋201室）の混住型国際寮が既にあり、価格は6.42万〜7.42万円。ここに同じ機能で並ぶと勝てない。
2. **狙うべき空白は3つ考えられる。**
   - 大学寮の入寮期間制限（原則1年、留学生最長2年）から**漏れる2年目以降の学生と、大学寮に落ちた学生**。
   - **他大学の学生**（大学寮は当該大学生限定。南茨木は大学横断で受けられる）。
   - **留学生ではないが国際環境を求める日本人学生**＝国内留学層。大学寮では枠が小さい（阪大の混住日本人枠は65戸程度／全体約1,000人規模）。
3. **相部屋前提は一度外して検討する。** 事例はほぼ個室ユニット。家賃低減は相部屋ではなく、専有面積の圧縮＋共用の充実（ユニット型）で達成されている。
4. **地域交流は「寮内イベント」ではなく、京都国際学生の家型の外部資金（助成・寄付・法人連携）と組み合わせて初めて持続している。** 収益には算入せず、費用側の一部を外部資金で賄う構造として設計するのが現実的。
5. **人が最大のコスト。** RA/RM相当を各ユニットに置くなら、その人数・報酬（寮費減免か給与か）・採用時期を月次運営費に明示する必要がある。現行の暫定数値モデル「運営費150万円/月」がこれを含むか未確定。

## 5. 未確認・次に取るべき裏取り

- 明治グローバル・ヴィレッジの実際の寮費（共立メンテナンス側の公表値）。民間所有・大学連携型の価格水準を知る最重要データ。
- 立命館OIC両寮の**日本人学生の受入枠数**（RM枠のみか、一般日本人枠があるか）。南茨木の顧客層が空いているかの判定に直結する。
- 阪大津雲台の混住ユニットにおける日本人応募倍率（国内留学需要の実測に最も近い公開指標）。
- 住総研論文「多文化の学びを育む混住型国際学生宿舎の研究」本文の設計要件（現在は要旨のみ確認）。
- ボーダレスハウス関西圏物件の稼働率・入居者属性（大学生比率）。民間単独で国際比率を維持できるかの実証データ。
