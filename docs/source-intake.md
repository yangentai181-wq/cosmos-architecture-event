## 課題設定

- 所在地: 大阪府茨木市東奈良三丁目328番1ほか
- 交通: 阪急京都線・大阪モノレール「南茨木」駅から徒歩3分
- 用途: 大学生向け学生寮の新規開発
- 敷地面積: 1,000㎡（想定）
- 延床面積: 3,600㎡（想定）
- 用途地域: 近隣商業地域
- 建蔽率 / 容積率: 80% / 300%
- 土地取得費: 7億円
- 要求収益: 投資回収15年以内、投資利回り7%以上
- 評価軸: 収益性、企画の魅力、チームの意欲、将来性

## ワークの順序

1. 周辺・商圏の現状と将来、学生・親・大学・地域のニーズを整理する。
2. コンセプトと各ステークホルダーへの価値を定める。
3. 平面計画と数値計画を往復して具体化する。
4. 企画概要、背景、コンセプト、周辺図、アプローチ、平面図、特徴、収益を発表資料にまとめる。

## 敷地読解

- 用地詳細図は、既存の分譲マンション計画と「今回の区画」を同じ図面に示している。
- 今回の学生寮区画は、用地詳細図の真北矢印を基準にすると図面上おおむね南西側の約1,000㎡。隣接マンションの住戸・エントランスを学生寮案として流用しない。
- 対象区画が直接接するのは主に大阪中央環状線側の交通空間と隣接マンション区画。生活道路・水路は一体開発外周にはあるが、対象区画への直接接道・直接隣接は図面から確定できない。正確な配置は確定筆界・測量図を基準にする。
- 建蔽率80%は上限であり、800㎡の建築面積が敷地形状・動線・空地条件に収まるかは平面検討で再確認する。

## 収益計算シートの構造

- 入力用タブは5枚（各128行×14列）。最新状態では先頭の「収支計算（簡易）」だけが入力済みで、残る4枚は未入力。
- 隠しマスタの主な単価:
  - S造 20万円/㎡・耐用25年
  - RC造 25万円/㎡・耐用50年
  - SRC造 31万円/㎡・耐用60年
  - 専有部内装 Rank D/C/B/A = 3/5/7/9万円/㎡
  - 外構・共用ランク Rank D/C/B/A = 3/6/9/12万円/㎡
- 廊下等は各階床面積の15%として自動計算される。
- 賃料粗利は賃料収入から管理費10%を控除し、運営費・修繕積立費・付帯事業利益を加減する。

## 確認が必要な不整合

1. 説明資料は「利回り7%以上」とする一方、同じスライドの式表記が「年間利益 ÷ 投資総額 ≦ 7%」になっている。数式の向きは誤記とみられる。
2. 説明資料は土地取得費7億円を明記しているが、収益計算シートの「原価」は建設コスト合計だけを参照し、土地代を含めていない。
3. 最新入力は建設費だけでも回収15.7年・利回り6.36%で条件外。土地代込みでは回収約25.3年・利回り約3.96%となる。最終評価前に採用基準を確認する。
4. 配布資料は計画段階のケースだが、2026年時点では東奈良三丁目の関連共同住宅2棟が竣工済み。以後の検討では「当時の仮想提案」と「実現物件を用いた事後検証」を混同しない。
5. 運営費の目安として2%、15〜20%、10〜15%が共有されたが、分母、対象費目、重複関係が未確定。月300万円の入力へはまだ置換しない。
6. 「テナントを入れれば収入になる」という認識に留保が追加された。賃貸条件、稼働率、費用、利益の帰属が未確認で、付帯事業の収益には算入しない。
