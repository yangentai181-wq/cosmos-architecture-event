# 7%資本ブリッジ｜家賃だけでなく投資上限から見る

- 基準日: 2026年9月4日
- 条件: 家賃10万円/月、稼働95%、`Day2判断表` の現行費用
- 状態: **行政確認前の感度比較。投資判断・見積ではない**

## 結論

84〜99室の比較枝は、土地を0円としても現在の建設費だけで7%の許容投資上限を超える。したがって、7%を維持するなら「土地価格だけを下げる」では届かず、建設費、家賃、室数、運営費、目標期間の複数条件を再設定する必要がある。

168室上限案は稼働95%の場合、総投資を7,085.7万円、3.82%下げれば計算上7%になる。ただし、168室自体の法規と実配置が未成立なので、これをコスト調整だけで採用できるとは読まない。

## 数式

```text
7%許容投資上限 = 現行条件の年間利益 ÷ 7%
必要削減額       = 現投資額 - 7%許容投資上限
建設後の土地上限 = 7%許容投資上限 - 現行建設費
```
