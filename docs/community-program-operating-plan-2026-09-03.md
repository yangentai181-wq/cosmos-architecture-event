# 地域・国際交流プログラム 初年度運営案

- 作成日: 2026-09-03
- 対応項目: `docs/current-direction-2026-09-03.md` 第11節「イベント活用の観点から企画内容を明日までに詳細化する」
- コンセプト: **「お互いが、留学先」**
- 位置づけ: 中間発表と空間設計へ渡す運営仮説。大学・自治体・学校・地域との合意済み計画ではない
- 収益上の扱い: 売上・助成・協賛金は0円とし、実績が確認できるまで家賃引下げの原資に算入しない

## 1. 結論

初年度は「国際交流イベント」を数多く開くのではなく、地域側にも目的が明確な**2本の定例候補と、1本の段階実証**に絞る。

1. **南茨木・多言語防災まち歩き**
2. **小中学校への留学生・日本人学生ペア派遣**
3. **お互い食堂｜一皿ずつ、先生になる。**

防災では、地域住民がまちの知識を学生へ教え、学生が多言語化やデジタル整理を担う。学校派遣では、留学生だけを「教える側」にせず、日本人学生と組み、日本と海外の生活文化を相互に伝える。どちらも「地域へ一方的にサービスする」のではなく、**互いが教える側・学ぶ側になる**ため、コンセプトと一致する。

食企画は一般公開から始めず、居住者内12人程度、招待制18人程度、外部実証24人の順に開く。詳細は `docs/otagai-shokudo-event-brief-2026-09-03.md` を正本とし、大きな食堂やイベントホールを先に固定しない。

### コンセプトから3案へつながる筋道

1. 留学生には日本で暮らすための生活知識、日本人学生には留学前の語学・異文化実践が必要である。
2. 既存寮にも混住はあるため、同じ建物に住むだけでは新しい価値にならない。
3. 互いの日常を相手の学びに変える関係を、**「お互いが、留学先」**と表現する。
4. その関係を寮内だけで閉じず、防災では地域知と多言語化、学校では生活文化、食堂では言葉・料理・生活知識を交換する。
5. 3案とも、参加人数や売上ではなく、次の共同活動、再参加、安全、運営負担を測る。

説明スライドと45秒原稿は `docs/concept-rationale-2026-09-03.md` を正本とする。

### 初年度の3案比較

| 企画 | 初回の規模・頻度 | 主な場所 | 責任主体の仮置き | 残す成果 | 収益の扱い |
| --- | --- | --- | --- | --- | --- |
| 多言語防災まち歩き | 約25人で1回。問題がなければ年1〜2回を検討 | 既存地域施設＋周辺市街地 | 寮運営者が総責任、地域・行政が情報確認 | やさしい日本語・多言語の防災マップ | 無料・売上0円 |
| 学生ペアの学校派遣 | 1学級で1回。学校評価後、1学期1回までを検討 | 学校 | 学校が教育・未成年者対応、寮運営者が派遣調整 | 再利用できる授業案と次回依頼 | 売上0円。謝金は確定後だけ別記 |
| お互い食堂 | 居住者12人→招待制18人→外部実証24人 | ピンクゾーンの交流キッチン・ラウンジ | 寮運営者が総責任、調理・衛生担当を別に置く | お互いパスポートと次の活動への申込 | 食材実費を仮説とし、基本収支へ算入しない |

規模・頻度は需要を示す調査結果ではなく、安全、動線、費用を測るための初期仮説である。

## 2. プログラムA: 南茨木・多言語防災まち歩き

### 目的

- 学生が地域の避難経路、危険箇所、病院、地域施設を知る
- 留学生にも分かる、やさしい日本語・多言語の防災情報をつくる
- 近隣住民にとって、学生寮が災害時に協力できる存在であることを示す
- イベント時の外来者動線、騒音、受付、安全管理を建物完成前から検証する

### 1回目の最小実証

| 項目 | 仮設定 |
| --- | --- |
| 参加者 | 居住想定学生10人、地域住民10人、運営・候補連携先5人程度 |
| 所要時間 | 90分。説明15分、まち歩き45分、地図更新20分、振り返り10分 |
| 集合・解散 | 東奈良コミュニティセンター等の既存施設を第一候補とし、新築前にも実施できる形にする |
| 成果物 | 避難先・危険箇所・支援拠点を示す、やさしい日本語と多言語の地域防災マップ |
| 開催頻度 | 最初は1回。重大事故・近隣苦情がなく、連携先と参加者の継続意向を確認後、年1～2回を検討 |
| 参加費 | 無料を基本仮説とする。費用負担者は未決定 |

参加人数と頻度は設計目標であり、需要を示す調査結果ではない。

### 当日の流れ

1. 受付で緊急連絡先、撮影可否、使用言語を確認する。
2. 地域住民が、浸水・交通・夜間・避難時に注意する場所を説明する。
3. 学生が2～4人の混成班に入り、経路と情報の分かりにくさを記録する。
4. 帰着後、学生が情報をやさしい日本語・英語等に整理する。
5. 地域住民が表現と場所を確認し、未確認情報は地図へ載せない。
6. 運営者が参加、事故、苦情、費用、改善点を記録する。

### 役割分担

| 担当 | 必須の役割 | 現時点の状態 |
| --- | --- | --- |
| 寮運営者 | 総責任、保険、名簿、緊急対応、会計、個人情報管理 | 未決定 |
| 学生コーディネーター | 班編成、多言語化、記録、振り返り | 入居者から公募する仮説 |
| 地域住民・自治会 | 地域知の提供、経路と表現の確認 | 未合意 |
| 東奈良コミュニティセンター | 集合場所・地域接点の候補 | 未照会 |
| 茨木市の防災担当等 | 公的情報の確認、教材・訓練協力の候補 | 未照会 |
| 近隣病院・企業・団体 | 救急・VR・教材等の協力候補 | 未照会。名称を確定して発表しない |

### 測る項目

- 申込数、当日参加数、学生・住民・言語別の構成
- 参加前後の「地域で避難できる」自己評価
- マップの修正件数と、確認できなかった情報
- 事故、体調不良、近隣苦情、無断撮影、個人情報事故
- 運営時間、外部支出、学生稼働時間、1人当たり費用
- 次回参加意向と、連携先の継続可否

## 3. プログラムB: 小中学校への学生ペア派遣

### 目的

- 小中学生が、身近な生活文化を入口に海外と日本の違いを知る
- 留学生が日本語・地域文化を学び、日本人学生が異文化説明と語学を練習する
- 新築施設へ子どもを呼ぶ前に、学校側の管理下で安全に内容を検証する

### 1回目の最小実証

| 項目 | 仮設定 |
| --- | --- |
| 実施者 | 留学生1人＋日本人学生1人＋寮運営者または学校担当者 |
| 対象 | 1学級。対象校・学年は学校側と協議して決める |
| 所要時間 | 授業1コマ程度。学校の時間割を優先する |
| 内容 | 「1日の暮らし」「学校」「食」「ごみ・防災」から学校が1テーマを選ぶ |
| 頻度 | 最初は1回。学校評価と運営負担を確認後、1学期1回までを検討 |
| 場所 | 学校を第一候補とする。寮へ未成年者を招く形式は第2段階 |

### 授業の流れ

1. 日本人学生が、留学生本人の希望と学校の学習目標をすり合わせる。
2. 2人が同じテーマを日本・海外の両側から紹介する。
3. 小中学生が質問し、留学生側も日本の暮らしについて質問する。
4. 「違いの紹介」だけで終わらず、共通点と一緒にできる行動を一つ決める。
5. 学校担当者が内容、安全性、教育上の適切さを評価する。

### 安全・責任条件

- 学校、教育委員会、既存の国際交流団体等、未成年者対応の責任主体を必ず通す。
- 学生だけで児童・生徒を引率しない。個人連絡先を交換しない。
- 写真・映像・氏名・作品の公開は、学校の同意手続を優先する。
- 政治、宗教、差別、戦争等を扱う場合は、学校側が内容を事前確認する。
- 学生の国籍を文化の代表と決めつけず、本人の経験として話してもらう。
- 通訳、交通費、教材作成、事前研修を無償労働として当然視しない。

### 測る項目

- 学校の再依頼意向と、授業目標への適合評価
- 児童・生徒、留学生、日本人学生の学び
- 準備・移動・授業・振り返りに要した時間
- 教材費、交通費、学生への報酬、運営者の稼働
- 不適切発言、撮影・個人情報、連絡先交換等の事故

## 4. プログラムC: 「お互い食堂」

防災と学校派遣の安全・運営体制を確認しながら、まず居住者内で始める。外部へ開くのは、両企画を含む運営体制を確認した後とする。コピーは**「一皿ずつ、先生になる。」**。世界の料理を食べるだけでなく、全員が言葉、料理、生活知識を一つずつ教え合う。

| 段階 | 対象 | 確認すること | 次へ進む条件 |
| --- | --- | --- | --- |
| 居住者内 | 居住学生12人程度 | 衛生、予約、片付け、言語補助 | 重大事故0、未処理苦情0、片付け手順を再現可能 |
| 招待制 | 居住学生＋既知の地域協力者、計18人程度 | 受付、外来者動線、撮影、アレルギー対応 | 専用部への侵入0、継続協力者を確認 |
| 外部実証 | 事前予約24人、150分 | 集客、参加費、入居関心、近隣影響、全費用 | 参加者の30%以上が次の活動へ申し込み、全費用を記録 |

- 一般公開は、必要な営業許可・届出の有無、食品衛生、保険、責任主体、近隣動線を確認した後に判断する。
- 寮運営者が総責任、調理・衛生担当が食材・加熱・アレルギー・清掃の責任を持つ。学生ホストだけへ責任を負わせない。
- 飲食売上を家賃還元の前提にしない。食材費・衛生管理・人件費を含む収支を別会計で記録する。
- 詳細な当日進行、安全条件、空間要件、判断基準は `docs/otagai-shokudo-event-brief-2026-09-03.md` を参照する。

## 5. 初年度の工程

| 時期 | 実施内容 | 次へ進む条件 |
| --- | --- | --- |
| 開業・実証前 | 連携候補への照会、責任主体、保険、個人情報、事故時対応を決める | 書面または議事録で分担を確認 |
| 1か月目 | 居住者オリエンテーション、学生コーディネーター公募・研修 | 担当者不在なら外部イベントを延期 |
| 2～3か月目 | 多言語防災まち歩きを1回実施 | 重大事故0、未処理の苦情0、継続協力者を確認 |
| 4～5か月目 | 学校派遣を1学級で1回実施 | 学校側の再実施可、学生側の負担を計測 |
| 6か月目 | 費用、参加、事故、苦情、学びを中間評価 | 継続・修正・中止を決定 |
| 7～9か月目 | 必要な修正後、どちらか1本を再実施 | 1回目より運営負担または事故要因が改善 |
| 10～11か月目 | 「お互い食堂」を居住者内で試行 | 衛生・予約・片付けが運用可能 |
| 12か月目 | 年次評価と翌年度計画 | 外部公開・頻度拡大・助成申請を判断 |

上表の時期と判定条件は初期案であり、連携先との協議後に確定する。

## 6. 建築へ返す空間要件

### 外部利用ゾーン（ピンク）

- 住居を通過せず入れる独立入口
- 受付、手洗い、バリアフリートイレ、清掃用具、施錠できる教材収納
- 防災地図を広げる、可動机と椅子を使う、少人数調理を試す、の3用途へ変えられる可変空間
- 外から活動が見えるが、居住者の顔・部屋・生活動線は見えない開口
- イベント終了時刻後に、外部利用部分だけを閉鎖できる境界
- 雨天時の集合、車椅子、ベビーカー、自転車待機を処理できる前庭または軒下

### 居住者専用ゾーン（グリーン）

- 外部利用者がエレベーター、階段、個室階へ入れない入退室管理
- 居住者がイベントへ参加せず帰宅・生活できる別動線
- イベント運営者が居住者情報を不必要に扱わない受付配置
- 各ユニット内の共有リビングは地域開放せず、日常の相互学習に限定

### 面積を確定する前に測ること

防災まち歩きは運営等を含む約25人、お互い食堂は居住者12人→招待制18人→外部実証24人として別に測る。食堂実証では、受付滞留、着席・立席比、荷物、掲示、片付け、音を記録する。その結果と避難・法規条件から必要面積を決める。既存の目的共用部810㎡をそのまま維持する根拠にも、全てをイベント床にする根拠にも使わない。

## 7. 運営費の記録様式

| 区分 | 記録する内容 | 収益計画への扱い |
| --- | --- | --- |
| 人件費 | 企画、交渉、研修、当日、翻訳、片付け、会計 | 無償前提にせず費用計上 |
| 会場・設備 | 会場、机椅子、音響、調理、清掃、警備 | 実額を記録 |
| 参加者費 | 交通、教材、食材、保険 | 実額を記録 |
| 広報 | 印刷、翻訳、申込管理 | 実額を記録 |
| 協賛・助成 | 企業、自治体、財団等 | 入金確定後だけ費用相殺として記録 |
| 参加費・売上 | 参加費、飲食・物販 | 継続実績が出るまで家賃収入へ合算しない |

各イベントで、`総費用 ÷ 実参加者数`、学生1人当たり稼働時間、運営者総稼働時間を算出する。

## 8. 継続・修正・中止の判断

### 継続

- 責任者と連携先が翌回も確保できる
- 重大事故と未処理の苦情がない
- 参加者だけでなく、学校・住民・学生の複数側に継続意向がある
- 人件費を含む費用が記録できている

### 修正

- 参加希望はあるが、時間、音、動線、準備負担のどれかに問題がある
- 特定の学生・国籍・担当者へ負担が偏る
- 外部利用と居住者の生活が干渉する

### 中止・縮小

- 責任主体、保険、未成年者対応、食品衛生を確定できない
- 近隣苦情や安全上の問題を改善できない
- 学生の無償労働またはイベント売上を前提にしないと成立しない

## 9. 中間発表へ載せる1ブロック

**見出し: 国際交流を目的にせず、地域課題を一緒に解く**

- 1本目: 地域住民から避難知識を学び、学生が多言語防災マップにする
- 2本目: 留学生と日本人学生がペアで学校へ行き、双方の生活文化を伝える
- 3本目: 一人一つ、言葉・料理・生活知識を交換する「お互い食堂」を段階的に開く
- 空間: 外部利用のピンクと居住者専用のグリーンを、入口・動線・時間で分ける
- 事業: 初年度は収益0円。参加、費用、事故、継続意向を測ってから拡大する

**一言メッセージ:** 「お互いが、留学先」を、イベント名ではなく、互いが教え合う運営で実現する。
