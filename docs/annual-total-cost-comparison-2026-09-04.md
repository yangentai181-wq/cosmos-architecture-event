# 南茨木・OIC周辺の年間総負担比較

- 確認日: 2026年9月4日
- 目的: 表面家賃ではなく、公開されている必須費用を年額へ直し、今回案の価格仮説と比較する
- 状態: **公開料金による比較。個別契約の見積・需要証明ではない**

## 結論

今回案の「家賃10万円」は年120万円で、食事、管理、光熱、ネット、寝具、初期費用を含まない。一方、OICの大学寮は光熱水費、インターネット、寝具を含む月6.42万〜7.42万円、コスモグラシア南茨木は食費・管理費・入館金を含む初年度主要費用が138.84万〜153.24万円である。

したがって、今回案は「家賃だけならコスモグラシアの主要費用レンジより低い」ものの、同じ費目まで加えた年間総負担は未定である。共同住宅99戸の土地込み7%に必要な家賃は、運営費の楽観比較でも年174.99万円、現行費用では年207.79万円で、どちらも食事等を含む前から既存3施設の公開水準を上回る。

### 計算の読み方

- I-Houseは居住費5万5,000円、光熱水・ネット7,200円、寝具2,000円の合計6万4,200円。入寮費は家賃1か月分5万5,000円、退去時清掃費1万円、契約事務手数料1万円。火災保険は金額未掲載のため、既知最低額へ含めない。
- G-Houseは住居費6万5,000円、寝具2,000円、水光熱・ネット7,200円の合計7万4,200円。公開要項は初期費用を別案内としているため、年額へ推測加算しない。
- コスモグラシアは家賃5万7,500〜6万9,000円、食費2万9,700円、管理費22万2,000円/年または1万9,000円/月、入館金12万円/1年。管理費年払いなら初年度138万8,400〜152万6,400円、月払いなら139万4,400〜153万2,400円である。
- 「年間継続費」は契約期間や退去費まで含むライフサイクル総額ではない。費目が同じではないため、単純な安い順にはしない。

## 判断

1. 今回案の価格表示を「家賃10万円」から「年額総負担の上限」へ変える。
2. 食事あり/なし、家具・寝具、光熱・ネット、管理・緊急対応を商品ごとに分ける。
3. 99戸案で7%を賃料だけから回収する設計は、既存価格との乖離が大きい。土地費、建設費、室数、付帯収益、目標利回りのどれを動かすかを先に決める。
4. 価格付き需要調査では、月額ではなく初年度総額と2年目以降総額を提示する。
