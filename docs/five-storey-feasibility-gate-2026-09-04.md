# 5階案の成立性ゲート

- 作成日: 2026年9月4日
- 状態: **行政確認・需要検証前の比較仮説**
- 対象: 「お互いが、留学先」の低層案
- 目的: 建築形状を描き込む前に、用途、床、外構、収支の矛盾を見つける

## 結論

現時点で5階案を確定してはいけない。ただし、検討を止める必要もない。

次の二つを並行した比較枝として残す。

1. **寄宿舎ルート:** 個室とユニット共用キッチンを優先し、コンセプトを守る
2. **共同住宅ルート:** 各住戸の独立設備を確保し、容積不算入の可能性を残す

どちらも、共有シートの168室・総延床3,600㎡をそのまま引き継がない。敷地全体へ容積率300%を適用できると仮定した行政確認前の比較値は、寄宿舎91室、共同住宅99戸である。配布図には用途地域境界を示すように見える表記があるため、この室数を上限とは呼ばない。さらに、駐車・駐輪だけで外構が圧迫されるため、B「角の交流核」の前庭を確保できるかは未成立である。

## 1. 一次資料から確定できる範囲

### 確認できたこと

- 国土交通省の2013年通知は、事業者が入居者を募集・管理し、複数人を居住させる「貸しルーム」を建築基準法上の寄宿舎として扱う考え方を示している。
- 共同住宅の共用廊下・共用階段は、建築基準法52条6項の容積率不算入対象になり得る。
- 共同住宅のエントランスホール・エレベーターホールは共用廊下に含み得る一方、ロビー、集会、作業、収納等の用途部分は含まれない。
- 共同住宅と他用途の複合建築物では、住戸専用、他用途専用、共用部分を分けて扱う。両者が使う廊下等は面積比による扱いが示されている。
- 茨木市の現行「審査指導課の事務分掌」は、建築基準法に基づく指導・許可等を同課の業務としている。別手引きには建築調整課の記載もあるため、相談前に審査指導課へ担当振分を確認する。
- 茨木市条例は、1,000㎡以上の土地における一定の建築行為を事前協議の対象としている。約1,000㎡という配布値では、確定測量前に対象外と判断できない。
- 茨木市の開発基準は、300㎡以上の敷地に道路側1.0m以上、1,000㎡以上の敷地に1.5m以上の基本空地を求め、原則として庇、門塀、ごみ置場、駐車・駐輪、植栽等を置けないとしている。

### まだ確定できないこと

- この学生寮が茨木市で寄宿舎・共同住宅のどちらに判定されるか
- 各室のミニキッチン等が共同住宅の独立した住戸機能として認められる条件
- 1階地域利用部が住宅付属共用部か、飲食店・集会場等との複合用途か
- 寄宿舎へ共同住宅と同じ容積不算入を適用できる部分があるか
- 対象筆の確定面積、接道、用途地域境界、高度地区、地区計画
- 駐車・駐輪台数の用途区分、端数処理、敷地外確保等の協議可否

## 2. 面積ルートの比較

計算は、敷地1,000㎡の全体へ指定容積率300%を適用できる場合として、目的共用部810㎡、廊下等540㎡という既存シートの区分を仮に維持した。配布図の用途地域境界が対象敷地内を通る場合は再計算が必要である。最大値ではなく、矛盾を発見するための比較値である。

| 項目 | 寄宿舎ルート | 共同住宅ルート |
| --- | ---: | ---: |
| 容積対象上限 | 3,000㎡ | 3,000㎡ |
| 容積不算入の仮置き | 0㎡ | 住戸専用廊下等540㎡ |
| 総延床の仮置き | 3,000㎡ | 3,540㎡ |
| 専有・寝室系 | 1,650㎡ | 2,190㎡ |
| 目的共用部 | 810㎡ | 810㎡ |
| 廊下等 | 540㎡ | 540㎡ |
| 室・戸数の暫定値 | 18㎡×91室 | 22㎡×99戸 |
| 5階の床構成例 | 600㎡×5層 | 1階740㎡＋上階700㎡×4層 |
| 建築面積の仮置き | 600㎡ | 740㎡ |
| 地上の残余 | 400㎡ | 260㎡ |

端数12㎡は壁、柱、設備シャフト、面積調整へ残す。この12㎡だけで十分という意味ではなく、実施設計には別途計画余白が必要である。

### 1階の公開・緩衝面積

B「角の交流核」の公開交流棟と緩衝・管理核は、**165㎡を初期図面の基準**、135〜200㎡を検証幅とする。現行計算の目的共用部810㎡の内訳であり、総床や目的共用部を追加する変更ではない。そのため、この配分だけでは下記の単純収支は変わらない。

廊下等15%を各階へ一律に当てる比較では、1階の残り方は次のとおりである。

| 5階ルート | 1階総床 | 1階可用面積 | 135㎡採用後 | **165㎡採用後** | 200㎡採用後 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 寄宿舎 | 600㎡ | 510㎡ | 375㎡ | **345㎡** | 310㎡ |
| 共同住宅 | 740㎡ | 629㎡ | 494㎡ | **464㎡** | 429㎡ |

165㎡の第一仮説は、可変ラウンジ65㎡、交流キッチン35㎡、受付・待合18㎡、トイレ・手洗い20㎡、管理・収納・清掃27㎡とする。残余は居住者ラウンジ、相談、宅配、備蓄、設備等の候補であり、実平面では壁、柱、縦動線、避難、用途区画を別途差し引く。

### 7個室＋共有リビングの実配置前比較

寄宿舎ルートの600㎡/階から廊下等15%の90㎡を引いた上階可用510㎡に、次の生活単位を3つ置く枝を追加した。

共有シートを引き継ぐ比較枝は次のとおりである。

| 1ユニットのシート継承値 | 面積 |
| --- | ---: |
| 個室7室 × 13.39㎡ | 93.73㎡ |
| 共有リビング | 24.50㎡ |
| 共用キッチン・水回り・玄関等 | 39.84㎡ |
| 合計 | 158.07㎡ |

158.07㎡×3ユニット＝474.2㎡で、上階の配置余裕は35.8㎡となる。これを2〜5階へ置くと、3ユニット×4層＝12ユニット、84個室である。1階は公開交流核、管理、居住支援へ使う。

別に、個室を有効12㎡、キッチン・衛生設備を要求数から積み上げ、内部動線12%と計画余白10%を順に見込む保守再算定も行った。この場合も1ユニットは丸め前158.0656㎡となる。

| 比較枝 | 個室 | 共有リビング | 設備・内部動線・余白 | 1ユニット | 土地込み利回り |
| --- | ---: | ---: | ---: | ---: | ---: |
| シート継承 | 13.39㎡×7 | 24.50㎡ | 39.84㎡を一括 | 158.07㎡ | **2.42%** |
| 保守再算定 | 12.00㎡×7 | 24.50㎡ | 設備19.80㎡＋内部動線15.40㎡＋計画余白14.37㎡ | 158.0656㎡ | **2.32%** |

**同じ158.07㎡は偶然一致であり、面積根拠が一致したわけではない。** シート継承枝には明示的な計画余白がなく、保守再算定枝は目的共用部の単価適用が増えるため建設費も上がる。

ただし、35.8㎡は階段、エレベーター、設備シャフト、柱、壁、避難、男女区画、全室採光を収められる証明ではない。個室13.39㎡も壁・収納・設備控除前で、共用設備39.84㎡も要求室数から積み上げていない。**84室は91室の面積比較例を平面へ近づける枝であり、採用案ではない。**

家賃10万円、稼働率95%、管理10%、固定運営費月300万円、修繕引当を同じ式へ入れると、シート継承枝は建設費9億7,410万円、年間利益4,044.3万円、土地込み利回り2.42%、回収41.39年、7%に必要な月額18万9,047円/室となる。保守再算定枝は建設費10億2,444万円、年間利益3,994.0万円、土地込み利回り2.32%、回収43.18年、必要月額19万3,719円/室である。

## 3. 居住人数は室数だけでは決まらない

現行計算は「1室10万円」を収入単位にしているが、1室へ1人住むか2人住むかが混在している。ここを分ける。

| ルート | 1室・1戸を1人利用 | 1室を2人利用 |
| --- | --- | --- |
| 寄宿舎91室 | 91人、10万円/人 | 182人、5万円/人。ただし18㎡を2人で使う受容性が未検証 |
| 共同住宅99戸 | 99人、10万円/人 | 2人利用は住戸面積・契約・生活品質を別途検証 |

「国内学生100人＋留学生100人」を守るために2人寝室を標準化しない。個室性と価格を提示した需要調査の結果から、人数目標を戻して決める。

## 4. 収支の再計算

### 前提

- 土地代7億円
- 稼働率95%
- 管理費率は実効賃料の10%
- 固定運営費は月300万円
- 年間修繕積立は建設費÷50年÷2
- 付帯事業利益0円
- 建設費は既存シートの単価式を面積区分へ適用した仮算定

| 指標 | 寄宿舎91室 | 共同住宅99戸 | 共有シート168室仮置き |
| --- | ---: | ---: | ---: |
| 建設費 | 9億7,410万円 | 11億3,610万円 | 11億5,410万円 |
| 土地込み投資 | 16億7,410万円 | 18億3,610万円 | 18億5,410万円 |
| 月額10万円・稼働95%時の年間利益 | 4,762.5万円 | 5,421.3万円 | 1億2,482.7万円 |
| 土地込み利回り | 2.84% | 2.95% | 6.73% |
| 回収年数 | 35.2年 | 33.9年 | 14.9年 |
| 7%に必要な月額/室・戸 | 17万4,505円 | 17万3,162円 | 10万2,900円 |

この表は事業採択判断ではない。固定運営費、建設単価、土地代、賃貸単位が未確認だからである。168室列は収支上の理論比較であり、法規・実配置の成立を示さない。ただし、室数を行政確認前の比較値へ戻すだけで土地込み7%から大きく離れ、必要賃料が上がる方向は確認できる。

### 感度の要点

- 月額12万円・稼働95%でも、土地込み利回りは寄宿舎3.96%、共同住宅4.06%に留まる。
- 月額15万円・稼働95%でも、寄宿舎5.63%、共同住宅5.72%で7%へ届かない。
- 付帯事業やイベント売上を未実証のまま差額へ入れない。

## 5. 外構の成立性

茨木市の2025年基準では、39㎡未満の単身者用共同住宅は、駅500m以内または商業・近隣商業地域で自動車を戸数×0.2台以上、自転車・単車を戸数×1台以上確保する基準が示されている。寄宿舎へ同じ区分を適用するか、地域利用分をどう加算するかは行政確認が必要である。

同基準を仮に適用し、端数を切り上げると次の規模になる。

| 項目 | 寄宿舎91室 | 共同住宅99戸 |
| --- | ---: | ---: |
| 自動車 | 19台 | 20台 |
| 車室だけの面積 | 218.5㎡ | 230.0㎡ |
| 自転車・単車 | 91台 | 99台 |
| 駐輪区画だけの面積 | 81.9㎡ | 89.1㎡ |
| 区画面積の単純合計 | 300.4㎡ | 319.1㎡ |
| 地上の残余 | 400㎡ | 260㎡ |
| 区画差引後 | 99.6㎡ | -59.1㎡ |

車路、転回、歩行、安全離隔、植栽、ごみ、搬入、消防活動、公開前庭、地域利用分の追加台数をまだ含んでいない。さらに道路側基本空地は駐車・駐輪等を置けない。したがって、平置きだけでは共同住宅ルートは成立せず、寄宿舎ルートも公開前庭を確保できる見込みが薄い。

比較すべき対策は次の順とする。

1. 行政へ適用区分、台数、端数、敷地外確保・緩和の扱いを確認する
2. 自転車ラック、屋内駐輪、機械式駐車、敷地外駐車の費用と動線を比較する
3. 室数または建築面積を減らし、B案の前庭・搬入・ごみ・消防空地を確保する
4. 地域利用部の規模を、実証時の同時利用人数から戻して決める

## 6. B「角の交流核」へ返す条件

B案は配置形状ではなく、次の運営原則として残す。

- 公開部を街側の一か所へ集約する
- 住宅、公開、搬入の入口を分ける
- 公開部だけを閉鎖できる
- 居住者の個室、郵便、帰宅動線を外来者へ見せない
- 24人のイベント実証を超える大空間を先に固定しない

行政回答と駐車・駐輪計画が出るまでは、街に面する「角」の位置、前庭面積、建築面積を固定しない。

## 7. 次の判断ゲート

| 順番 | 判断 | 通過条件 |
| ---: | --- | --- |
| 1 | 用途・容積 | 茨木市が寄宿舎・共同住宅の判断条件と不算入範囲を回答 |
| 2 | 外構 | 駐車・駐輪・搬入・ごみ・消防・前庭を敷地内外で処理できる |
| 3 | 居住商品 | 個室、2人室、共用設備、総費用を提示した需要調査で選好を確認 |
| 4 | 事業収支 | 土地代、空室、全運営費、修繕、税・金融費用を含む条件で成立 |
| 5 | 建築案 | 4条件を満たす5階案をA/B/C配置で再比較 |

## 8. 現時点の推奨

設計の第一仮説は、**5階・個室中心・小ユニット・B「角の交流核」**のまま維持する。ただし最初の室数比較は84〜99室の幅で保留し、実配置前比較の下端を84室とする。168室・168人、1階800㎡、土地込み7%を同時達成する前提は外す。

行政回答前に描く図面は、面積を確定した平面図ではなく、公開・緩衝・居住・駐輪・搬入の関係を示すブロック図までとする。
