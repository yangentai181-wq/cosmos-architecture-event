# 総月額の競合比較と需要判定ゲート

- 作成日: 2026年9月4日
- 状態: **公開価格の比較と調査設計。需要実績ではない**
- 対象: 南茨木の国内留学型学生住宅

## 結論

本計画の「家賃10万円」は、周辺施設の**総月額**と同じ数字ではない。管理費、光熱、ネット、食事を加える前の収支入力である。

一方、周辺の公開値は、大学寮の食事なし総月額が6万4,200〜7万4,200円、コスモグラシア南茨木の食事・管理込み月額が、管理費の支払方法により約10万5,700〜11万7,700円である。本計画は、家賃だけで10万円、法規比較案で7%を満たすには家賃だけで17万3,162〜19万3,719円が必要になる。

したがって、発表では「家賃10万円で市場に合う」と言わない。学生本人と保護者には、家賃ではなく年間初期費用を含む総支払額を提示し、価格帯ごとの離脱を測る。

## 調査で提示する価格帯

本人・保護者には「家賃」ではなく、家賃・管理・光熱・ネット・食事を含む**月額総費用**として次を示す。

| 総月額 | 目的 |
| ---: | --- |
| 7万円 | 大学寮価格に近い下限 |
| 9万円 | 大学寮と民間食事付きの間 |
| 11万円 | 民間食事付きの中心帯 |
| 13万円 | 交流・相談等の追加価値を含む上側 |
| 15万円 | 高価格帯の許容確認 |
| 17万円 | 共同住宅99戸の必要家賃へ近づく境界。ただし居住者負担の追加費用は別 |
| 19万円以上 | 84室比較の必要家賃に近い事業成立側の検証 |

価格は順番固定にせず、可能なら回答者ごとに提示順を変える。同時に、食事、家具家電、24時間相談、個室、交流参加自由、大学連携など、含まれる条件を固定する。

## 室数別の内部判定

国内学生・留学生の構成は未確定なので、国籍別の固定比率ではなく、合計の強い意向と各募集経路を分けて確認する。

| 価格表示後の強い意向 | 判断 |
| ---: | --- |
| 25人未満 | 新築寮を中核にせず、既存施設で企画を実証する |
| 25〜41人 | 84室案の半数未満。コンセプト、価格、対象を再設計する |
| 42〜49人 | 84室案の半数相当。詳細検討の入口だが、建設判断には不足 |
| 50人以上 | 84〜99室案の半数以上。法規・運営費と並行して検討を続ける |
| 84人以上 | 84室案に相当するが、解約率、入居時期、支払者確認、留学生募集を別に確認する |

「強い意向」は単なる関心ではない。部屋条件と総月額を見た後の、有料体験、見学予約、または返金条件を明示した予約金意思を指す。実際の決済・個人情報取得・外部公開は承認後に行う。

## 今日の停止線

- ローカル調査画面へ価格選択肢を置くところまで進める。
- 回答の外部送信・保存、広告配信、謝礼購入、予約金受領はしない。
- 茨木市回答と運営見積が来るまで、17〜19万円帯を「推奨価格」とは呼ばない。
- 総額11万円帯で需要が集中し、17万円以上で離脱する場合は、7%目標、土地条件、室数、建て方のいずれかを変更する。
